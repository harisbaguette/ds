# 디자인 시스템

현재 화면 검토: [패토브 — 브랜드·클릭 가능한 사전·이미지](시안/2026-09-23/패토브-재설계/README.md). 대표 패턴 16개의 시안이며, 웹 화면 7곳을 조사해 불필요한 문구와 장식을 줄이고 목록·상세·스타일을 갱신했다.

디자인 패턴 사전과 스타일별 디자인 시스템을 만들고, shadcn처럼 부품을 코드로 가져와 조합하는 묶음으로 배포해, AI가 그 안에서 찾고 고르고 조합해 완성하게 하는 저장소다. 그 목표·구성요소·패턴을 문서로 정리해 둔다. 문서마다 맡는 질문이 하나씩이라 같은 내용이 두 곳에 없다. 아래 순서로 읽는다.

| 순서 | 문서 | 내용 |
|---|---|---|
| 1 | [디자인 시스템 정의](<문서/디자인 시스템 정의.md>) | 목표, 원하는 것, 원하지 않는 것 |
| 2 | [구성요소 계층표](<문서/구성요소 계층표.md>) | Token→Page 여덟 층으로 나눈 구성요소 410개와 따로 정의할 영역 46개 |
| 3 | [패턴 사전 색인과 사용법](<문서/패턴 사전 색인과 사용법.md>) | 사전을 읽는 기준, 66개 분류 색인, 항목에 붙일 정보 규격, 완료 기준 |
| 4 | [사전/](<문서/사전/>) | 분류별 수록 항목 3915개, 분류마다 한 파일(`번호-ID-분류명.md`) |
| 5 | [레퍼런스 출처 대장](<문서/레퍼런스 출처 대장.md>) | 출처 기호표와 원문 주소, 남이 해결해 둔 것과 우리에게 남는 일, 탐색 기록 |
| 6 | [HTML까지 재사용하는 구현 조사](<문서/HTML까지 재사용하는 구현 조사.md>) | 아이콘·세부 부품의 개별 배포, shadcn과 HTML의 관계, 공통 자산과 환경별 구현, 구현 순서와 확인할 조건 |

문서 밖에, 마음에 든 컨셉과 이미지를 모아 두는 [영감보관함/](<영감보관함/>)이 따로 있다. 정리된 규칙이 아니라 재료를 쌓아 두는 곳이다. 정의 문서의 취향 절은 이 보관함의 이미지를 근거로 쓴다.
