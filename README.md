# 디자인 시스템

**패토브 뼈대: [화면 열기](index.html)** · [구조·범위](DESIGN.md)

`index.html`을 브라우저로 열면 된다. 또는 `npm run dev` 후 `http://127.0.0.1:4173`에서 본다.
별도 설치나 빌드 없이 동작한다. 스타일 선택 → 패턴 그리드 → 상세로 이어지며,
12개 항목은 구조 검토용 예시다. 상세 본문·실제 데모·전체 사전 데이터는 뼈대 확정 후 만든다.
저장은 현재 브라우저의 localStorage에 보관된다.

현재 검토 대상은 **스타일 중심의 간결한 사이트 외부 구조**다. 첫 화면에서 스타일을 고르고,
그 안에서 검색·분류로 패턴을 찾는다. 비교·리스트·정렬·큰 제목·로고 텍스트를 제거했다.
저장은 보조 기능으로 남기고 스타일별로 묶었다. 탐색 화면에서 `/` 키로 검색창에 이동한다.
내부 예시와 상세 내용의 추가 작업은 뼈대 확정 뒤 진행한다.

화면 구현은 `src/`, 브랜드 자산은 `assets/`에 있다. 예시는 `src/data/catalog.js`,
미리보기는 `src/ui/previews.js`, 화면 구조는 `src/ui/views.js`, 이동·저장은 `src/app.js`에서 관리한다.
아래 시안 폴더는 설계와 변경 이력으로 보관한다.

개발 검증: `npm install` → `npm test`, `npm run test:outer`, `npm run test:visual`. Playwright Chromium이 없는 환경에서는
`npx playwright-core install chromium`을 먼저 실행한다. 검증 결과와 캡처는 `test-results/`에 생성된다.
`npm run dev`가 실행 중이면 `npm run test:design`으로 조작 크기·텍스트 대비·읽기 순서를 추가 검수한다.
