# 레퍼런스 출처 대장

[패턴 사전 색인과 사용법](<패턴 사전 색인과 사용법.md>)의 수록 항목과 [구성요소 계층표](<구성요소 계층표.md>)의 구성요소를 만들며 확인한 출처를 한곳에 모은 문서다. 사전 항목의 근거 칸에 적힌 출처 기호는 아래 기호표에서 원문으로 이어진다. 출처를 열었다는 것과 그 자료를 우리 시스템으로 구현·검증했다는 것은 구분한다.

## 2026-09-23 UI 스킬 참고 자료 추가

사용자가 제시한 `frontend-design`, `apple-design`, `beautiful-shadows`, `accessibility`, `design-review`, `emil-design-eng`, `shadcn`, `adapt`, `better-interface`, `interaction-design`의 본문과 적용 근거를 [UI 스킬 적용 분석](<UI 스킬 적용 분석.md>)에 등록했다. 각 자료의 제공 페이지·저자 원문·패토브 시안에 반영한 결정을 함께 기록했다. `apple-design`은 기존 `[E]` 출처를 다시 대조한 항목이다. 주소 없이 이름만 제공된 `interaction-design`은 wshobson 자료를 보완 출처로 명시했다.

[현재 패토브 브랜드와 사전 시안](<../시안/2026-09-23/패토브-재설계/README.md>)은 KAWAI식 미니어처 구조에 상황 검색·비교·전체 스타일·저장을 반영했다. 대표 패턴 16개를 실제 구현하고 브라우저에서 75개 항목을 확인했다. 이전 갈피는 미채택했다. 전체 사전 구현이나 사용자 연구를 마친 결과와 구분한다.

[MDN dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)와 [WAI-ARIA APG Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)를 초점·닫기·배경 비활성의 구현 근거로 추가 확인했다. 이름의 1차 검색과 여덟 문제의 수정 근거는 [재설계 기록](<../시안/2026-09-23/패토브-재설계/재설계-근거.md>)에 남겼다.

## 2026-09-23 화면 현행화 조사

로고와 기본 사전 구조를 유지하고 불필요한 부제·설명·반복 장식을 제거하라는 사용자 요구를 반영했다. Cosmos, Layers, Recent, Curated, Minimal Gallery, ui.land, KAWAI의 현재 공개 화면 7곳을 실제 브라우저로 열었다. [원문 주소·캡처·적용 근거](<../시안/2026-09-23/패토브-재설계/화면-현행화.md>)에 연결한다. Godly 주소는 이번 열람에서 Recent로 이동했다.

1440×1080 초기 화면에서 첫 미리보기는 453px에서 166px로, 온전히 보이는 카드는 6개에서 9개로 바뀌었다. 전체 목록 텍스트는 공백 제외 1,173자에서 432자로 줄었다. [측정 조건과 결과](<../시안/2026-09-23/패토브-재설계/전후-비교.json>)를 남겼으며, 이 수치를 미적 품질이나 사용성의 증명으로 해석하지 않는다.

## 추가 조사에서 항목에 연결한 출처

2026년 9월 22일 조사로 이 표의 기호 주소를 기호표에 등록했다. 등록 결과는 아래와 같다.

- **주소를 등록한 기호 32개**: `AND`, `AND16`, `CHKUI`, `CNIL2`, `DAANGN`, `DECEPTIVE`, `DOCU`, `FL2`, `FTVIZ`, `GHOST`, `HIG`, `HOOKED`, `KINTONE`, `LAWSUX`, `LGR`, `LINEDS`, `M3`, `M3E`, `MTL`, `OCTA`, `OGP`, `PASSKEY`, `POL2`, `RDXP`, `SIGNAGE`, `SPC2`, `SQPOS`, `TATE`, `TOSSMINI`, `UIP`, `W3I18N`, `WCAG22`
- **셋으로 나눈 기호 1개**: `AIMISC`는 서로 다른 세 자료를 한 기호로 묶고 있었다. `AIMISC-MCP`(도구 연결 규격), `AIMISC-GENUI`(생성형 UI 지침), `AIMISC-HALLU`(불확실성 표시 지침)로 분리해 각각 주소를 등록했다. `[AIMISC]`를 쓰고 있던 항목 5개는 실제로 어느 자료가 뒷받침하는지 하나씩 확인해, 생성형 UI 항목은 `[AISDKUI]`로, 도구 연결 표시와 환각 경고 항목은 모델 지식에 원문 대조를 붙인 표기로 바꾸고, 원문에서 확인되지 않은 두 항목은 `확장 [MK]`로 되돌렸다. 이제 `[AIMISC]` 표기를 쓰는 항목은 없다.
- **주소를 등록하지 않은 기호 2개**: `BAEMIN`, `KRWEB`. 사유는 아래 "주소를 찾지 못한 기호와 그 사유"에 적었다.
- **주소가 필요하지 않은 기호 1개**: `MK`는 AI 모델이 이미 알고 있던 내용을 표시하는 우리 쪽 표기이므로 외부 원문이 없다. 주소 미등록 상태가 정상이다.

주소를 등록한 32개 가운데 5개(`M3`, `HIG`, `AND`, `LGR`, `M3E`)는 주소가 실재하는 것은 확인했으나 본문을 기계로 읽어내지 못했다. Apple·Google 공식 문서가 화면을 그릴 때 내용을 채워 넣는 방식이어서, 주소만 받아 오면 본문이 빈 채로 온다. 이 다섯은 **주소 확인·본문 미검증**으로 구분해 둔다.

### 여섯 저장소에서 사전으로 옮긴 내용

여섯 저장소의 수록 내용을 사전의 기존 항목과 한 건씩 대조해, 겹치지 않는 것만 새로 실었다. 새로 실은 항목은 모두 76개다. [THISRESP]에서 화면 배치 11개·탐색 13개·표 처리 5개·이미지 1개, [AIDUI]에서 금지 항목 12개, [CERBERUS]에서 메일 항목 14개, [A11YFORM]에서 입력 6개·접근성 3개, [MCSTYLE]에서 문구 규칙 11개다. 이미 같은 개념을 다른 이름으로 싣고 있던 항목 31개에는 근거 칸에 `대조` 표시를 덧붙여, 어느 원문이 같은 내용을 확인해 주는지 남겼다. 우선순위 내비게이션, 유동 영상, 아트 디렉션과 `srcset`, 가짜 마감·가짜 재고, 비교 표는 이미 사전에 있어 새로 싣지 않았다.

[AWEDS]에 모여 있는 디자인 시스템 163건은 패턴 항목이 아니라 참고처 목록이므로, 목록 전체를 이 대장으로 옮기지 않았다. 163건의 주소를 기호표에 등록된 주소와 기계로 대조한 결과 13건(Adobe Spectrum, Ant Design, Apple 디자인 지침, Atlassian, AWS Cloudscape, Chakra UI, GitHub Primer, GitLab Pajamas, IBM Carbon, NHS 서비스 매뉴얼, Radix, shadcn/ui, 미국 정부 디자인 시스템)은 이미 개별 기호로 등록되어 사전 항목의 근거로 쓰이고 있었다. 나머지 150건은 아직 어떤 항목의 근거도 아니어서, 근거로 실제 인용하는 시점에 개별 기호를 붙이기로 하고 [AWEDS] 한 건으로 찾아가게 두었다. 근거로 쓰지 않는 주소를 기호표에 미리 채우면 기호표가 사전 항목과 어긋나기 때문이다.

### 새 저장소에서 사전으로 옮긴 내용

[APGIMPL]·[LZA11Y]·[COPILOTGUI]가 확인해 준 패턴은 이미 [APG]·[AISDKUI]·[MK] 근거로 사전에 실려 있던 항목과 대부분 같은 개념이었다. 새 항목을 만드는 대신 근거 칸에 `대조` 표시를 9곳에 추가했다. [APGIMPL]은 ACT-15(작업 도구 모음), ACT-21(메뉴 바), DAT-19(중첩 행 표 — Treegrid), LAY-43(창 분할 리사이저 — Window Splitter) 4곳에 다중 프레임워크 구현 확인을 더했다. [LZA11Y]는 ACS-16(시간 제한 연장), STR-09(확대 400%), ARI-93(건너뛰기 링크) 3곳에 국내 기업의 실제 채택 사례를 더했다. [COPILOTGUI]는 AIX-59(생성형 UI)·AIX-65(생성형 UI 세 갈래) 2곳에 [AISDKUI]와 독립적인 두 번째 출처를 더해 신뢰도를 높였다.

[A11YCOMP]에서는 기존 사전에 없던 항목 2개를 새로 실었다. INP-92 "입력창 지우기 버튼 — Clear Text Field Button"(텍스트 입력칸의 X 아이콘으로 내용을 한 번에 비우는 보조 버튼)과 ARI-110 "링크와 버튼의 역할 선택 기준"(이동은 링크, 화면 안 상태 변경은 버튼이라는 행동 기준)이다. 나머지 11개 범주(아코디언·브레드크럼·디스클로저·모달·스위치·탭·툴팁 등)는 이미 사전 전반(ATM·ACT·03-NAV 등)에 실려 있어 새로 싣지 않았다.

[FLOWB]·[PRELINE]·[SHADCNST]·[GLUEUI]는 [AWEDS] 때와 같은 방식으로 처리했다. 네 저장소가 제공하는 개별 컴포넌트(버튼·카드·모달·내비게이션 등 수백 종)를 하나씩 사전 항목과 대조해 옮기지 않았다. 이미 ATM(284개)·INP(92개)·ICO(526개) 등 기존 분류가 같은 종류의 부품을 훨씬 촘촘하게 다루고 있어, 전면 대조는 저장소 성격상 개별 항목 추출보다 참고처 등록이 맞다고 판단했다. 네 기호는 앞으로 특정 항목의 실제 구현 예시가 필요할 때 근거로 인용하는 참고 기호로 남긴다. [PRELINE]은 기존에 이 대장 뒤쪽 참고 표에 "요청 경로 없음" 상태로 얕게만 올라 있었는데, 이번에 별 수·라이선스·갱신일을 실제로 확인해 정식 기호로 승격했다.

## 출처를 찾아다닌 기록

설명·코드·앱 흐름·시각 갤러리는 서로 다른 증거다. 아래는 공개 출처의 탐색 기록이며, 방문한 사이트의 모든 하위 페이지를 읽었다는 뜻이 아니다. 소개 페이지를 확보한 출처, 항목 목록을 확보한 출처, 실제 본문을 읽어 사전 항목에 연결한 출처를 구분한다.

탐색의 시작점을 [Design Systems Repo](https://designsystemsrepo.com/design-systems/), [The Component Gallery의 디자인 시스템 목록](https://component.gallery/design-systems/), [Awesome Design Systems](https://github.com/alexpate/awesome-design-systems)로 교차 확장했다. 세 디렉터리도 세계의 모든 출처를 보장하는 목록은 아니다. 별도로 shadcn 계열·전문 도구·플랫폼 문서·일본 디자인 아카이브·실사용 앱 흐름을 조사했다.

## 원래 제공한 레퍼런스와 본문 복구 기록

Curated Design·Design Diversity·Hallmark·Monet는 기존 정의와 이번 목록에 연결했다. 제공한 X 게시물 8개의 본문·인용 연결과 해석은 [디자인 시스템 정의의 레퍼런스 조사](<디자인 시스템 정의.md>)에 기록되어 있다. 게시물 소개, 소개된 프로젝트의 실제 기능, 그 프로젝트의 실행 품질은 각각 구분한다.

- X 원문 직접 접근이 막힌 경우 공개 FxTwitter 응답으로 본문을 읽고, 가능한 공식 syndication 응답과 대조한 기존 기록을 사용했다.
- Apple HIG는 JavaScript 안내만 보이는 페이지 대신 공식 공개 DocC JSON의 본문을 확인했다. 예: [Gestures 본문 데이터](https://developer.apple.com/tutorials/data/design/human-interface-guidelines/gestures.json).
- freee Vibes는 Storybook 겉화면 대신 공개 [항목 색인](https://vibes.freee.co.jp/index.json)을 확인했다. 색인 확인과 모든 데모 조작 완료는 다르다.
- Orbit는 도메인 접근 실패 뒤 [공식 저장소의 컴포넌트 목록](https://github.com/kiwicom/orbit/tree/master/packages/orbit-components/src)을 확인했다.
- Welie는 [공개 패턴 페이지](https://www.welie.com/patterns/)의 안내만 추출되어 개별 패턴 목록이 확보되지 않았다. Designing Interfaces의 [패턴 주소](https://designinginterfaces.com/patterns/)도 접근하지 못했다. 두 자료의 전체 본문을 확인했다고 표시하지 않는다.
- Figma Community, 로그인·유료 아카이브, 동적 렌더만 제공하는 페이지는 공개 설명과 실제 자료 열람의 범위를 구분한다. 우회해 본문을 확보하지 못한 경우 미확인으로 남긴다.
