# 3. 탐색과 현재 위치

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 3번 분류 NAV다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| NAV-01 | 헤더와 주 탐색 — Header / Navigation | 모듈 | 사이트 정체성과 주요 경로 제공 | 확인 [C] |
| NAV-02 | 메가 메뉴 — Mega Menu | 모듈 | 많은 경로를 범주별로 탐색 | 확인 [K] |
| NAV-03 | 접히는 탐색 메뉴 — Hamburger Menu | 구성 | 좁은 공간에서 탐색을 열기 | 확인 [K] |
| NAV-04 | 사이드바 탐색 — Sidebar Navigation | 모듈 | 자주 오가는 작업 영역 표시 | 확인 [S] |
| NAV-05 | 하단 탭 바 — Bottom Tab Bar | 모듈 | 모바일의 주요 목적지 전환 | 확인 [K] |
| NAV-06 | 탭 — Tabs | 부품 | 관련 콘텐츠 패널 전환 | 확인 [S] |
| NAV-07 | 분할 선택 — Segmented Control | 부품 | 소수의 배타적 보기·조건 전환 | 확인 [C] |
| NAV-08 | 현재 위치 경로 — Breadcrumb | 부품 | 상위 구조와 현재 위치 표시 | 확인 [C] |
| NAV-09 | 목차·앵커 탐색 — Table of Contents | 모듈 | 긴 페이지의 필요한 구간으로 이동 | 확인 [K] |
| NAV-10 | 페이지 이동 — Pagination | 부품 | 구분된 결과 페이지를 탐색 | 확인 [S] |
| NAV-11 | 더 보기·연속 불러오기 | 구성 | 목록을 단계적으로 확장 | 확인 [UN] |
| NAV-12 | 명령 팔레트 — Command Palette | 모듈 | 검색으로 기능과 목적지 실행 | 확인 [S] |
| NAV-13 | 푸터 탐색 — Footer | 모듈 | 보조 경로와 운영 정보 제공 | 확인 [C] |
| NAV-14 | 본문 바로 가기 — Skip Link | 부품 | 반복 탐색 영역 건너뛰기 | 확인 [C] |
| NAV-15 | 맨 위로 이동 — Back to Top | 부품 | 긴 페이지의 시작으로 복귀 | 확인 [PF] |
| NAV-16 | 워크스페이스·조직 전환 | 모듈 | 작업 대상 조직을 바꿔 이동 | 확인 [SHR] |
| NAV-17 | 앱 전환 런처 — App Switcher | 모듈 | 연결된 여러 제품 사이 이동 | 확장 [ATL] |
| NAV-18 | 넘치는 탐색의 보조 메뉴 | 구성 | 폭 밖의 항목을 다른 경로로 제공 | 확인 [PF] |
| NAV-19 | 다단계 드릴다운 탐색 | 구성 | 좁은 화면에서 분류를 한 단계씩 탐색 | 확장 [APG] |
| NAV-20 | 문서 버전 전환 | 모듈 | 같은 문서의 버전을 구분해 이동 | 확장 · 기술 문서 요구 |
| NAV-21 | 이전 맥락·스크롤 복원 | 구성 | 상세에서 돌아와 탐색 이어가기 | 확장 [GEL] |
| NAV-22 | 지역·언어 전환 | 모듈 | 현재 콘텐츠의 다른 언어판으로 이동 | 확인 [USW] |
| NAV-23 | 사이트 전체 지도 페이지 | 모듈 | 모든 페이지를 한 곳에 계층으로 나열 | 확장 [MK] |
| NAV-24 | 고정·즐겨찾기 탐색 항목 | 구성 | 자주 가는 곳을 사용자가 탐색에 고정 | 확장 [MK] |
| NAV-25 | 탐색 항목의 알림 배지 | 부품 | 메뉴 옆 미읽음 개수·새 소식 점 | 확장 [MK] |
| NAV-26 | 앱 내 뒤로·앞으로 이력 탐색 | 구성 | 브라우저와 별개로 앱 안 방문 이력을 되돌리기 | 확장 [MK] |
| NAV-27 | 스크롤 방향에 따른 바 숨김·복귀 | 구성 | 내릴 때 숨기고 올릴 때 다시 보이는 탐색 바 | 확장 [MK] |
| NAV-28 | 탐색 레일 — Navigation Rail | 부품 | 태블릿 폭에서 세로로 세운 아이콘 탐색 | 확장 [MK] |
| NAV-29 | 페이지 제목 영역 — Page Header | 부품 | 제목·설명·주 행동·경로를 묶은 상단 | 확장 [MK] |
| NAV-30 | 태그·주제 구름 탐색 | 구성 | 주제 목록을 크기·빈도로 보여 주고 이동 | 확장 [MK] |
| NAV-31 | 가나다·알파벳 색인 점프 | 부품 | 긴 목록 옆 글자 색인으로 바로 이동 | 확장 [MK] |
| NAV-32 | 페이지 전환 진행 띠 | 부품 | 상단 얇은 띠로 다음 화면 불러오는 중 표시 | 확장 [MK] |
| NAV-33 | 유틸리티 바와 주 탐색의 2단 헤더 | 구성 | 언어·로그인 같은 보조 링크 줄을 위에 따로 | 확장 [MK] |
| NAV-34 | 오버플로 메뉴 — OverflowSet | 부품 | 공간이 부족하면 남는 항목을 "더보기"로 밀어 넣는 묶음 | 확인 [FL2] |
| NAV-35 | 단계 목록 — Step List | 부품 | 여러 단계 중 지금 어디인지 줄지어 보여주는 표시 | 확인 [SPC2] |
| NAV-36 | 탭 고르개 — Tabs Picker | 부품 | 탭이 너무 많을 때 나머지를 드롭다운으로 접음 | 확인 [SPC2] |
| NAV-37 | 서비스 전용 상단 메뉴 바 — Service Navigation | 구성 | 서비스명 옆에 붙는 해당 서비스 전용 상단 메뉴 바 | 확인 [G] |
| NAV-38 | 페이지 내 목차 이동 — In-Page Navigation | 부품 | 긴 글 옆에 붙어 클릭하면 해당 섹션으로 이동하는 목차 | 확인 [USW] |
| NAV-39 | 스크롤 연동 페이지 내 목차 — Anchor(스크롤 스파이) | 부품 | 스크롤 위치에 맞춰 현재 섹션을 강조하는 페이지 내 목차 | 확인 [ANT] |
| NAV-40 | 수평 메뉴 — Horizontal Menu | 부품 | 가로로 나열한 상단 메뉴 항목 묶음 | 확인 [DC] |
| NAV-41 | 페이지 카운터 — Page Counter | 부품 | 여러 페이지 중 현재·전체 쪽수를 숫자로 표시 | 확인 [DC] |
| NAV-42 | 사이드 드로어 — Side Drawer | 구성 | 화면 옆에서 밀려 나오는 전체 높이 메뉴 패널 | 확인 [LINEDS] |
| NAV-43 | 여정 전체 단계 목차 — Step by Step Navigation | 모듈 | 여러 화면·서비스에 흩어진 절차 전체를 하나의 목차 지도로 묶어 지금 몇 단계인지 보여줌 | 확인 [G] |
