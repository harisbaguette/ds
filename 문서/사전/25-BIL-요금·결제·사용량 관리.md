# 25. 요금·결제·사용량 관리

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 25번 분류 BIL다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

|---|---|---|---|---|
| BIL-01 | 결제 수단 선택·등록 | 모듈 | 지원 수단으로 결제 정보 입력 | 확인 [PAY] |
| BIL-02 | 결제 주소·수령 주소 연결 | 구성 | 필요한 주소를 중복 입력 없이 지정 | 확인 [PAY] |
| BIL-03 | 기본 결제 수단 변경 | 모듈 | 다음 청구에 쓸 수단 선택 | 확인 [STR] |
| BIL-04 | 청구 내역·영수증·인보이스 | 모듈 | 거래별 내역과 증빙 확인 | 확인 [STR] |
| BIL-05 | 구독 변경의 적용 시점 | 구성 | 다음 청구와 즉시 변경을 구분 | 확인 [STR] |
| BIL-06 | 구독 해지·일시 중지·재개 | 흐름 | 영향 확인 → 상태 변경 → 결과 | 확인 [STR] |

| BIL-16 | 쿠폰·프로모션 코드 입력 | 부품 | 결제 전 코드 적용과 결과 | 확장 [MK] |
