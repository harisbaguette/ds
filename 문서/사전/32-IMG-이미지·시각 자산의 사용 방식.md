# 32. 이미지·시각 자산의 사용 방식

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 32번 분류 IMG다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| IMG-01 | 기기별 이미지 구도 선택 | 구성 | 작은 화면에서도 주 대상 보존 | 확장 [CLIP] |
| IMG-02 | 피사체와 설명의 여백 방향 | 기준 | 시선·동작 방향에 맞춰 글 배치 | 확장 [CUR] |
| IMG-03 | 제품 누끼와 배경 관계 | 구성 | 제품의 형태·재질을 명확히 전달 | 확장 [LP] |
| IMG-04 | 환경 사진과 사용 맥락 | 구성 | 실제 사용 장면으로 대상 설명 | 확장 [MU] |
| IMG-05 | 인물 사진의 시선·크기 구성 | 구성 | 인물과 내용의 관계 표현 | 확인 [SAN] |
| IMG-06 | 일러스트 묶음의 표현 규칙 | 기준 | 선·비율·시점·음영을 일관되게 관리 | 확장 [SPIN] |
| IMG-07 | 인포그래픽과 설명의 연결 | 모듈 | 시각 자료와 근거를 함께 읽기 | 확인 [GEL] |
| IMG-08 | 전후 이미지 비교 슬라이더 | 구성 | 같은 대상의 변화 직접 비교 | 확인 [HFP] |
| IMG-09 | 이미지의 정보 핫스폿 | 모듈 | 특정 위치에서 설명·행동 제공 | 확인 [HFP] |
| IMG-10 | 마스크·클리핑 프레임 | 구성 | 이미지와 주변 도형의 경계 구성 | 확장 [COD] |
| IMG-11 | 작품의 원본 비율 보존 | 기준 | 감상 대상의 구도 손상 방지 | 확장 [CLIP] |
| IMG-12 | 영상 표지와 재생 진입 | 구성 | 재생 전 내용과 시작 행동 전달 | 확장 [GEL] |
| IMG-13 | 3D 대상 회전·상세 보기 | 모듈 | 입체 대상의 다른 면 확인 | 확장 [COD] |
| IMG-14 | 이미지 없는 항목의 대체 표현 | 구성 | 자료가 없어도 위계·기능 유지 | 확장 · 콘텐츠 운영 요구 |
| IMG-15 | 아이콘 그림·심볼 크기 단계 | 기준 | 아이콘 크기 몇 단계로 쓸지 | 확장 [MK] |
| IMG-16 | 로딩 중 흐린 이미지 — Blur-up / LQIP | 구성 | 작은 흐림 사진 먼저 보이기 | 확장 [MK] |
| IMG-17 | 반응형 이미지 소스 선택 | 구성 | 화면에 맞는 크기 파일 고르기 | 확장 [MK] |
| IMG-18 | 이미지 게으른 로딩 | 구성 | 보일 때 불러오기 | 확장 [MK] |
| IMG-19 | 배경 이미지 위 글자 대비 보정 | 구성 | 그림 위 글자 읽히게 어둡게 | 확장 [MK] |
| IMG-20 | SVG 아이콘 색 상속·상태 색 | 구성 | 아이콘 색이 글자색 따라감 | 확장 [MK] |
| IMG-21 | 일러스트 톤 — 선·면·질감 통일 | 기준 | 그림 스타일 한 가지로 | 확장 [MK] |
| IMG-22 | 장식 이미지와 정보 이미지 구분 | 기준 | 뜻 있는 그림과 꾸밈 구분 | 확장 [MK] |
| IMG-23 | 아바타 대체 — 이니셜·색 생성 | 구성 | 사진 없을 때 이름 첫 글자 | 확장 [MK] |
| IMG-24 | 이미지 저작권·출처 표시 위치 | 구성 | 사진 아래 작은 출처 | 확장 [MK] |
| IMG-25 | 스크린샷 기기 프레임·그림자 | 구성 | 제품 화면 사진의 꾸밈 규칙 | 확장 [MK] |
| IMG-26 | 이미지 확대 줌·팬 | 구성 | 상세 그림을 확대해 이동 | 확장 [MK] |
| IMG-27 | GIF·짧은 영상 대체 이미지 | 구성 | 움직이는 그림의 정지 대체 | 확장 [MK] |
| IMG-28 | 이미지 비율 자리 확보 — 레이아웃 이동 방지 | 구성 | 그림 오기 전 자리 미리 잡기 | 확장 [MK] |
| IMG-29 | 사진 필터·보정 프리셋 | 구성 | 올린 사진의 색 톤 맞추기 | 확장 [MK] |
