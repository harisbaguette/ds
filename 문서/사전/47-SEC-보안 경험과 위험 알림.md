# 47. 보안 경험과 위험 알림

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 47번 분류 SEC다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

보안을 사용자가 이해하고 따르게 하는 화면이다. 겁주지 않으면서 무엇을 해야 하는지 한 번에 보인다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| SEC-01 | 비밀번호 강도·규칙 실시간 표시 | 구성 | 조건 충족을 체크로 보이기 | 확장 [MK] |
| SEC-02 | 유출된 비밀번호 경고 | 구성 | 알려진 유출과 겹치면 알림 | 확장 [MK] |
| SEC-03 | 새 기기 로그인 알림·차단 | 흐름 | 낯선 접속을 알리고 막기 | 확장 [MK] |
| SEC-04 | 보안 점검 — 계정 안전 점수 | 모듈 | 할 일 목록으로 보안 상태 | 확장 [MK] |
| SEC-05 | 2단계 인증 설정 유도 | 흐름 | 켜야 하는 이유와 절차 | 확장 [MK] |
| SEC-06 | 복구 방법 등록 — 이메일·전화·코드 | 흐름 | 잃어버렸을 때 대비 | 확장 [MK] |
| SEC-07 | 피싱 의심 링크 경고 | 구성 | 낯선 주소 열기 전 확인 | 확장 [MK] |
| SEC-08 | 민감 작업 재인증 — Step-up Auth | 구성 | 중요한 일 전에 다시 확인 | 확장 [MK] |
| SEC-09 | 세션 잠금·자동 로그아웃 예고 | 구성 | 곧 나감을 알리고 연장 | 확장 [MK] |
| SEC-10 | 권한 요청 설명 — 왜 필요한지 | 구성 | 권한마다 이유 한 줄 | 확장 [MK] |
| SEC-11 | 공유 링크 위험 안내 | 구성 | 누구나 볼 수 있음을 표시 | 확장 [MK] |
| SEC-12 | 계정 탈취 의심 시 조치 안내 | 흐름 | 비밀번호 바꾸고 세션 끊기 | 확장 [MK] |

| SEC-14 | 개인정보 마스킹 표시 — 카드 뒷자리 | 부품 | 일부만 보이는 값 | 확장 [MK] |
| SEC-15 | CAPTCHA 대안·접근 가능한 봇 검사 | 구성 | 보이지 않는 검사 우선 | 확장 [MK] |
