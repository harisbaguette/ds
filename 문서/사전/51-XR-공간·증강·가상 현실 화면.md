# 51. 공간·증강·가상 현실 화면

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 51번 분류 XR다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

머리에 쓰거나 카메라를 통해 보는 화면의 항목이다. 평면 규칙을 그대로 옮기지 않고, 멀미·피로·안전을 먼저 본다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| XR-01 | 공간 창·패널 배치 | 구성 | 눈앞 공간에 띄운 창의 거리·크기 | 확장 [MK] |
| XR-02 | 시선·손 제스처 선택 | 구성 | 보고 집는 조작 | 확장 [MK] |
| XR-03 | 공간 앵커 — 현실에 고정된 물체 | 구성 | 책상 위에 놓인 채 남는 콘텐츠 | 확장 [MK] |
| XR-04 | 몰입 정도 조절 — 창·부분·완전 몰입 | 구성 | 현실이 얼마나 보이는지 단계 | 확장 [MK] |
| XR-05 | 안전 경계·이동 경고 | 구성 | 벽·장애물 가까이 알림 | 확장 [MK] |
| XR-06 | 멀미 완화 — 이동 방식 선택 | 기준 | 순간 이동·터널 시야 등 옵션 | 확장 [MK] |
| XR-07 | 공간 음향 단서 | 구성 | 소리로 방향 알리기 | 확장 [MK] |
| XR-08 | AR 물체 배치·크기 조절 | 구성 | 카메라 화면에 물건 놓기 | 확장 [MK] |
| XR-09 | AR 안내 표시 — 화살표·라벨 | 구성 | 현실 위에 겹친 안내 | 확장 [MK] |
| XR-10 | 손 추적 실패·대체 입력 | 구성 | 컨트롤러·음성으로 대체 | 확장 [MK] |
| XR-11 | 장시간 사용 휴식 안내 | 구성 | 피로 방지 알림 | 확장 [MK] |
| XR-12 | 공간 텍스트 가독성 규칙 | 기준 | 거리별 글자 크기 | 확장 [MK] |
| XR-13 | 현실 사람·화면 지나감 표시 | 구성 | 누가 다가오면 보여 주기 | 확장 [MK] |
| XR-14 | XR 전용 앱바·대화상자 — XR App Bar / XR Dialog | 구성 | 공간(XR) 화면 전용으로 만든 상단 바·대화상자 | 확인 [LGR][AND16] |
