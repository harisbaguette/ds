# 66. 명령줄 인터페이스

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 66번 분류 CLI다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

글자만으로 조작하는 화면이다. 버튼도 색도 없지만 도움말·오류 문장·진행 표시·설정 우선순위가 모두 정해진 부품이며, 사람이 직접 치는 경우와 다른 프로그램이 호출하는 경우를 함께 만족시켜야 한다. 그래픽 화면의 규칙을 그대로 옮기면 어긋나므로 분류를 따로 둔다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| CLI-01 | 도움말 세 단계 — 인수 없음·`-h`·`--help` | 기준 | 아무것도 안 붙이면 짧은 사용법, `-h`는 요약, `--help`는 전체 | 확인 [CLIG] |
| CLI-02 | 예시 중심 도움말 | 구성 | 옵션 나열보다 실제로 치는 예시를 먼저 보여 준다 | 확인 [CLIG] |
| CLI-03 | 하위 명령 도움말 | 구성 | 명령마다 자기 도움말을 가진다 | 확인 [CLIG] |
| CLI-04 | 사람이 읽는 오류 문장 | 기준 | 중요한 부분을 문장 끝에 두고, 무엇을 하면 되는지 함께 적는다 | 확인 [CLIG] |
| CLI-05 | 오류 보고 안내 | 부품 | 예상 못 한 오류에는 신고 주소와 기록 파일 위치를 적는다 | 확인 [CLIG] |
| CLI-06 | 진행 표시와 남은 시간 | 부품 | 오래 걸리는 작업에 진행률과 예상 시간을 보여 준다 | 확인 [CLIG] |
| CLI-07 | 사람 화면이 아닐 때 진행 표시 끄기 | 기준 | 다른 프로그램으로 넘길 때는 돌아가는 표시를 내지 않는다 | 확인 [CLIG] |
| CLI-08 | 표준 출력과 표준 오류 분리 | 기준 | 결과는 출력으로, 안내·경고는 오류 쪽으로 보낸다 | 확인 [CLIG] |
| CLI-09 | 기계가 읽는 출력 — `--json` | 구성 | 사람이 볼 표와 프로그램이 읽을 형식을 따로 둔다 | 확인 [CLIG] |
| CLI-10 | 꾸밈 없는 출력 — `--plain` | 구성 | 표 그림·색을 뺀 줄 단위 출력 | 확인 [CLIG] |
| CLI-11 | 색 끄기 규칙 | 기준 | `NO_COLOR` 환경 변수, `TERM=dumb`, `--no-color`를 모두 존중한다 | 확인 [CLIG] |
| CLI-12 | 색 강제 켜기 — `FORCE_COLOR` | 기준 | 파이프로 넘길 때도 색을 유지해야 하는 경우 | 확인 [CLIG] |
| CLI-13 | 긴 출력의 쪽 넘김 | 구성 | 화면을 넘는 출력은 쪽 단위로 보여 준다 | 확인 [CLIG] |
| CLI-14 | 되묻기는 사람 화면에서만 | 기준 | 사람이 직접 치는 상황이 아니면 묻지 않고 실패시킨다 | 확인 [CLIG] |
| CLI-15 | 되묻기 끄기 — `--no-input` | 구성 | 자동 실행에서 멈추지 않게 하는 스위치 | 확인 [CLIG] |
| CLI-16 | 미리 보기 — 실제로 하지 않기 | 구성 | 무엇이 바뀔지만 보여 주고 실행하지 않는 모드 | 확인 [CLIG] |
| CLI-17 | 위험한 작업은 이름을 치게 하기 | 흐름 | 예·아니오가 아니라 대상 이름을 직접 입력받는다 | 확인 [CLIG] |
| CLI-18 | 되돌릴 수 없는 작업의 경고 문장 | 부품 | 무엇이 사라지는지 개수와 함께 적는다 | 확인 [CLIG] |

| CLI-20 | 표준 옵션 이름 | 기준 | `-v`, `-q`, `-o`, `-f`, `--version` 등 관례를 따른다 | 확인 [CLIG] |
| CLI-21 | 명사 다음 동사 순서 | 기준 | `도구 대상 동작` 순서를 명령 전체에서 일관되게 쓴다 | 확인 [CLIG] |
