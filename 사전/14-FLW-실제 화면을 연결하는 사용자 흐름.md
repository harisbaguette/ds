# 14. 실제 화면을 연결하는 사용자 흐름

[디자인 패턴 사전 항목 목록](<../디자인 패턴 사전 항목 목록.md>)의 14번 분류 FLW다. 항목 ID·종류·근거 표기 규칙은 목록 문서의 "목록을 읽는 기준"을 따른다.

아래 흐름은 앞의 항목을 연결한 **우리 프로젝트의 조합 후보**다. 새로운 부품으로 복제하지 않고, 사용하는 항목과 상태 전달을 연결한다. 플랫폼과 스타일마다 검증한다.

| ID | 항목 | 종류 | 연결할 과정 | 근거 |
|---|---|---|---|---|
| FLW-01 | 찾아서 읽고 이어 보기 | 흐름 | 검색·목록 → 글 → 관련 글·저장 | 확장 [BL], [UN] |
| FLW-02 | 상품을 비교하고 선택하기 | 흐름 | 목록·조건 → 비교·상세 → 판매처 이동 | 확장 [BC] |
| FLW-03 | 입력하고 결과 받기 | 흐름 | 자료 입력 → 처리 → 결과·다운로드·재시도 | 확장 · 기능 사이트 요구 |
| FLW-04 | 작성 내용을 확인하고 제출하기 | 흐름 | 단계별 입력 → 확인·수정 → 제출·완료 | 확장 [GC], [GE] |
| FLW-05 | 지표에서 문제 항목 찾기 | 흐름 | 대시보드 → 조건 변경 → 목록 → 상세 | 확장 [DT], [CH] |
| FLW-06 | 항목을 만들고 수정하기 | 흐름 | 목록 → 작성·검증 → 저장 → 수정·취소 | 확장 [UI] |
| FLW-07 | 처음 시작하고 핵심 기능 쓰기 | 흐름 | 진입 → 필요한 가입·설정 → 첫 작업 | 확장 [UO], [OB] |
| FLW-08 | 계정 접근 복구하기 | 흐름 | 로그인 실패 → 복구 → 재로그인 | 확장 [LI], [B] |
| FLW-09 | 주문하고 상태 확인하기 | 흐름 | 상품 선택 → 장바구니 → 결제 → 결과 | 확장 [UM], [PD] |
| FLW-10 | 긴 문서를 탐색하고 출력하기 | 흐름 | 목차 → 본문·근거 → 인쇄·다운로드 | 확장 · HTML 문서 요구 |
| FLW-11 | 찾은 결과를 저장하고 알림 받기 | 흐름 | 검색·필터 → 저장 → 새 결과 알림 | 확장 [MK] |
| FLW-12 | 초대 링크로 들어와 참여하기 | 흐름 | 링크 → 가입·로그인 → 참여 완료 | 확장 [MK] |
| FLW-13 | 문제를 신고하고 처리 결과 받기 | 흐름 | 신고 → 접수 확인 → 결과 알림 | 확장 [MK] |
| FLW-14 | 구독하고 요금·해지 관리하기 | 흐름 | 요금제 선택 → 결제 → 변경·해지 | 확장 [MK] |
| FLW-15 | 자료를 올리고 공유하기 | 흐름 | 업로드 → 정리 → 링크 공유·권한 | 확장 [MK] |
| FLW-16 | 예약하고 변경·취소하기 | 흐름 | 시간 선택 → 확인 → 변경·취소 | 확장 [MK] |
| FLW-17 | AI에 시키고 결과 다듬어 쓰기 | 흐름 | 요청 → 결과 → 부분 수정 → 내보내기 | 확장 [MK] |
| FLW-18 | 동료와 함께 검토하고 승인받기 | 흐름 | 작성 → 검토 요청 → 수정 → 승인 | 확장 [MK] |
| FLW-19 | 데이터를 가져와 정리하고 분석하기 | 흐름 | 가져오기 → 정리 → 시각화 → 공유 | 확장 [MK] |
| FLW-20 | 알림에서 들어와 처리하고 돌아가기 | 흐름 | 알림 → 해당 화면 → 처리 → 원래 자리 | 확장 [MK] |
| FLW-21 | 계정을 지우고 자료 챙기기 | 흐름 | 내보내기 → 삭제 확인 → 유예 | 확장 [MK] |
| FLW-22 | 인증서 발급 단계 인디케이터 — Certificate Issuance Step Indicator | 흐름 | 공동인증서·금융인증서 발급 절차를 단계별로 보여주는 인디케이터 | 확장 [KRWEB] |
| FLW-23 | 남은 단계 수 표시 — Steps Left | 흐름 | 진행 막대 대신 글자로 몇 단계가 더 남았는지 알려 줌 | 확인 [UIP] |
| FLW-24 | 먼저 써 보고 나중에 가입 — Lazy Registration | 흐름 | 가입 없이 기능부터 써 보게 하고 필요할 때만 가입을 요구함 | 확인 [UIP] |
| FLW-25 | 시작 전 유의사항 화면 — Interruption Page | 구성 | 본 절차에 들어가기 직전에 준비물·걸리는 시간·주의점을 한 화면으로 끊어 보여줌 | 확인 [G] |
