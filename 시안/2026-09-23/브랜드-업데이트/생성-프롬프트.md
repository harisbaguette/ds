```text
용도: logo-brand. 한국어 UI 패턴 사전 웹 서비스 “갈피 / galpi”의 완성도 높은 브랜드 아이덴티티 시트 1장을 만들어라. 가로 1536×1024. 제품 성격은 패턴 이름과 쓰임을 실제 미니어처로 찾아보는 시각 사전이다. 한국 편집 디자인 스튜디오가 만든 차분하고 또렷한 그래픽 시스템, 평면의 정확한 정면 배치. 밝은 종이색 #F7F8F4 배경, 먹색 #20272B, 짙은 청록 #176E7A, 소량의 색인노랑 #F2D45C, 연한 하늘색 #E6F4F5. 
핵심 로고 “갈피표”: 열린 책을 장황하게 그리지 말고, 세로로 약간 긴 사전 카드 한 장의 정교한 먹색 윤곽, 오른쪽 위 하나의 접힌 모서리, 왼쪽 내부에는 아래가 V로 잘린 짧은 청록 책갈피 리본 하나. 24px에서도 읽히는 아주 단순한 2색 벡터형 기호. 일반적인 파란 앱 네모가 아니다. 같은 정확한 기호를 모든 적용에 반복한다.

하단 48%는 얇은 선으로 나눈 3개의 정확한 모듈. 왼쪽 “작은 크기에서도” 아래 같은 로고의 흑백/청록 2가지와 작은 실사용 크기 두 개; 임의의 픽셀 치수 라벨은 쓰지 않는다. 가운데 “색과 글자” 아래 5개 단정한 색 조각과 “갈피  가나다  Aa  0123” 글자 샘플. 오른쪽 “화면 속 갈피” 아래 실제 웹 헤더 조각: 작은 로고+갈피, 패턴 / 스타일 / 영감, 단정한 검색 입력. 헤더 아래에는 작은 “빈 상태” 미니어처 한 개: 가는 검은 선으로 된 빈 카드 트레이와 아주 작은 노란 책갈피. 로고 자체와 일러스트의 선 언어가 통일되어야 한다.
```


## 02-데스크톱-사전.png

참조: ../사전-웹화면/01-탐색-목록.png, 01-브랜드-로고.png.

생성 원본 파일: `exec-a349c772-65f6-458d-8529-c48ffa35836e.png`.

생성 지시:

```text
용도: ui-mockup. 한국어 UI 패턴 시각 사전 “갈피”의 실제 제품 데스크톱 화면 시안. 1536×1024 가로 3:2, 정면의 정확한 웹앱 스크린샷, 캔버스 전체를 UI가 채운다.
입력1은 개선할 기존 사전 목록 화면이다. 입력2는 새 브랜드 정본으로, 동일한 접힌 카드+청록 책갈피 기호와 “갈피” 워드마크를 가져온다.
핵심 구조: 상단 헤더, 좌측 분류, 3열 × 3행의 패턴 미니어처 갤러리. 실제 예시가 먼저 보이는 KAWAI식 사전 구조를 반드시 유지한다. 대신 전체 비례와 여백, 타이포, 미니어처를 새로 정밀하게 조율한다.
제품 외곽: 균일한 밝은 종이색 #F7F8F4, 흰 표면 #FFFFFF, 먹색 글자 #20272B, 짙은 청록 #176E7A 활성색. 밝고 균일한 화면, 그림자는 팝오버 미니어처와 아주 약한 카드 경계에만. 표면은 평평하고 또렷하다.
헤더 높이 72px. 왼쪽 작은 갈피표와 선명한 “갈피”. 옆으로 “패턴” 현재 선택에 짧은 청록 밑줄, “스타일”, “영감”. 중앙-오른쪽 430px 너비 검색창 “이름이나 쓰임으로 검색”과 작은 돋보기, 오른쪽 작은 테마 아이콘. 헤더와 본문 사이는 1px 옅은 선.
왼쪽 분류 232px 너비. 위쪽 작은 “패턴 분류”. 행간 넉넉한 메뉴 “전체 패턴”, “탐색”, “레이아웃”, “입력”, “데이터 표시”, “상태와 피드백”, “콘텐츠”, “행동”, “모바일”, “오류”. “탐색” 선택은 연한 청록 바탕+왼쪽 청록 세로선+진한 글자로 보인다. 아이콘은 한 세트의 정교한 1.5px 먹선. 맨 아래 작은 책갈피 아이콘과 “저장한 패턴”.
본문 32px 바깥여백. 상단 “탐색” 25px 제목, 그 아래 작게 “화면을 오가고, 현재 위치를 알려주는 패턴”. 오른쪽 그리드/목록 작은 전환. 이 영역은 높이 76px, 큰 히어로가 아니다.
카드는 3열, 16px 간격, 각각 8px 반경. preview 부분 62%, 하단 제목/쓰임/태그 38%. 상단 미니어처는 연한 중성색 또는 거의 흰 하늘색 바탕. 하단 설명은 흰 바탕에 짙고 읽기 좋은 한국어. 미니어처는 wireframe만이 아니라 정말 작동하는 실제 부품을 잘 축소한 모습, 제한적인 청록 활성과 먹색, 작은 노랑 포인트. 같은 일반 상자 복제 금지.
아래 9카드를 정확하게:
1 햄버거 메뉴 — “메뉴를 접고 펼칩니다.” 실제 로고/메뉴버튼 헤더 밑에 홈·프로젝트·설정 작은 팝오버. 태그 “모바일”.
2 탭 바 — “주요 화면을 전환합니다.” 홈/검색/저장/설정 아이콘과 라벨 4개, 홈만 청록 활성. 태그 “탐색”.
3 브레드크럼 — “현재 위치와 상위 경로를 보여줍니다.” 집 아이콘 > 프로젝트 > 상세. 태그 “경로”.
4 사이드바 — “메뉴를 한쪽에 모아 둡니다.” 좌측 네 줄 메뉴+오른쪽 내용, 한 항목 청록. 태그 “데스크톱”.
5 메가 메뉴 — “많은 링크를 묶어서 보여줍니다.” 제품/솔루션/리소스의 3열 드롭다운, 좁지만 정교함. 태그 “웹”.
6 페이지네이션 — “목록을 페이지로 나눕니다.” 이전·1·2·3·…·12·다음, 2 청록 채움. 태그 “목록”.
7 무한 스크롤 — “아래로 내리면 더 불러옵니다.” 실제 3행 콘텐츠와 아래 작은 로딩점. 태그 “목록”.
8 고정 헤더 — “스크롤해도 머리글을 유지합니다.” 얇은 먹색 헤더에 흰 글자 “갈피”, 아래 연한 내용 행들. 태그 “웹”.
9 드로어 — “화면 옆에서 패널이 열립니다.” 실제 좌측 흰 패널, 닫기 X, 오른쪽만 회색 딤. 태그 “탐색”.
정교한 현대 한국어 고딕, 16px급 카드 제목, 14px 설명, 12px태그의 차이가 잘 보인다. 기존 대비 로고/타이포/카드 비례/미니어처 언어가 개선되어야 한다. 홈페이지 홍보문, 수치 통계, 코드, 설치, 다운로드, 커다란 일러스트 배경은 만들지 않는다. 모든 카드 끝이 이미지 안에 보이도록 구성.
```

## 03-패턴-상세.png

참조: ../사전-웹화면/03-빈-상태-상세.png, 02-데스크톱-사전.png.

생성 지시:

```text
용도: ui-mockup. 1536×1024, 한국어 UI 사전 “갈피”의 빈 상태 패턴 상세 화면을 정면 웹앱 스크린샷으로 정밀하게 생성한다.
입력1은 개선할 기존 상세 모달, 입력2는 확정된 새로운 갈피 목록 UI다. 입력2의 로고, 헤더, 서체, 청록 선택색, 종이색 바탕, 얇은 선, 좌측 분류, 3열 미니어처 갤러리와 같은 제품이어야 한다.
뒤에는 “상태와 피드백” 카테고리의 갤러리: 토스트, 알림상자, 진행표시, 스켈레톤, 빈 상태, 오류 등의 작은 실제 UI 미니어처가 있다. 배경에 중성 회색 반투명 딤만 깔려서 갈피 로고와 분류 구조가 보인다. 중앙 흰색 모달은 가로 약800px, 세로약900px, 상하 62px 여백, 12px모서리. 모달 가장자리는 부드러운 중립 그림자, 밝고 또렷한 내용.
모달 상단은 왼쪽 작은 “상태와 피드백” 레이블, 다음줄 굵은 “빈 상태”와 작게 “Empty State”. 오른쪽에 저장 책갈피 아이콘과 닫기 X, 각44px크기의 여유 있는 영역.
그 아래 본체 가로전체의 큰 preview, 높이275px. 연한 하늘종이 #E6F4F5 배경의 모서리8px패널. 중앙 작은 검정+흰색 고양이가 비어있는 사각 트레이를 들여다보고, 위에 작은 노란 책갈피 하나가 떠 있다. 살짝 불규칙한 섬세한 먹선, 단순한 평면 일러스트. 고양이는 전체화면의 작은 부분만 차지한다. 실제 빈 상태 구성으로 그림 아래 “저장한 항목이 없어요”, 보조문구 “마음에 드는 패턴을 모아보세요.”, 청록 버튼 “첫 항목 추가”. 글자와 버튼을 충분히 크게.
그 다음 “표현” 레이블과 가로3개의 낮은 선택 타일. 각각 실제같은 빈 상태 미니썸네일과 한글 이름:
“기본”: 기하학적 tray 아이콘만 사용한 중립적인 빈 상태.
“선화”: 현재의 흑백 고양이와 트레이 그림, 청록 2px경계+작은 체크로 선택 표시.
“색면”: 먹색/청록/노랑의 평평한 도형으로 된 트레이와 카드.
모두 같은 빈 상태 의미와 정보 구성을 공유하지만 이미지 표현만 다르다. 세 타일높이90px정도.

맨아래 “관련 패턴”과 “로딩”, “오류”, “온보딩” 작은태그.
전체 한국어 타이포 매우 선명하고 정확하게, 본문은읽을수있는짙은회색, 정교한 정상웹앱밀도. 모든내용과하단이완전히캔버스안에보인다. 로고와모달의색이같아야한다. 코드/설치/다운로드/복사 버튼, 커다란홍보카피, 장식포스터, 글로우, 기울어진기기목업 없이 실제사용화면처럼.
```

수정 지시:
