# KAWAI 기준 웹 사전 시안

이후 업데이트: [패토브 브랜드와 클릭 가능한 사전 시안](../패토브-재설계/README.md). 아래는 브랜드 적용 전의 구조 검토 기록이다.

사용자가 지정한 [KAWAI 영상](https://x.com/kawai_design/status/2091284281658048996/video/1)을 확인하고, 검색·좌측 분류·3열 미니어처 목록·중앙 상세 모달이라는 웹 사전 구조로 제작한 세 화면이다. 앞선 여섯 칸 표본판은 현재 방향에 해당하지 않는다.

| 이미지 | 보여 주는 장면 |
|---|---|
| [01 탐색 목록](01-탐색-목록.png) | 메뉴·탭·현재 위치·페이지 이동 등의 작은 실물과 이름·짧은 용도를 함께 훑는다 |
| [02 상태와 피드백](02-상태와-피드백.png) | 분류 선택에 따라 토스트·진행·로딩·빈 상태·오류 등의 미니어처가 보인다 |
| [03 빈 상태 상세](03-빈-상태-상세.png) | 목록 위에 큰 미리보기, 스타일 선택, 개요·사용 조건·다른 상태·관련 패턴이 열린다 |

외곽은 흰색·회색과 얇은 경계로 정리했다. 영감보관함의 선과 제한된 색은 미리보기의 표현과 상태 삽화에 적용했다. 원본 서비스의 로고와 108개라는 수치는 이 프로젝트의 것으로 표시하지 않았다.

## 실제 확인한 참조

- [KAWAI 원문](https://x.com/kawai_design/status/2091284281658048996): X 화면 직접 열람은 빈 페이지로 나왔으나, 공식 공개 임베드에서 게시글 본문과 영상 주소를 확보했다. 약 32초짜리 [영상 파일](참조/kawai-post-2091284281658048996.mp4)을 내려받아 0·6·12·16·18·24·28·30초 프레임을 확인했다. 이름과 움직이는 미니어처를 함께 나열하고, 카드를 열면 상세 모달이 나타난다.
- [KAWAI UI Design Dictionary](https://ui-design-dictionary.pages.dev/): 실제 브라우저에서 [목록](참조/kawai-index.png)과 [Accordion 상세](참조/kawai-detail.png)를 확인했다. 프로젝트의 레퍼런스 출처 대장에도 해당 X 게시글과 이 사이트의 연결이 기록되어 있다.
- [shadcn/ui](https://ui.shadcn.com/): 실제 홈페이지를 열어 [화면](참조/shadcn.png)을 확인했다. 단정한 화면 틀과 실제 부품을 보여 주는 방식을 참고했다.
- 영감보관함의 `루틴-체크-격자-myturn`, `일러스트레이터-명함-흑백-karita`, `간식-든-흑백-고양이-선화` 원본을 열람하고 이미지 생성의 참조로 입력했다.

## 제작 및 범위

내장 `image_gen`으로 제작한 정적 PNG 시안이다. 실제 미니어처의 애니메이션이나 클릭 동작을 구현한 웹사이트는 아니다. 배경의 예시 카드와 미리보기 내용은 화면별로 일부 다르며, 실제 데이터와 연결된 전환 캡처가 아니다.

[사용한 생성 프롬프트](생성-프롬프트.md)를 함께 보관한다. 프로젝트 원본 문서와 영감 이미지는 수정하지 않았다.
