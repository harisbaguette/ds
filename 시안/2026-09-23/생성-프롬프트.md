# 디자인 시스템 자체의 시안 생성 프롬프트

생성 도구: 내장 `image_gen`. 사용자 교정을 반영해 예시 앱 대신 패턴 사전·부품 라이브러리·스타일별 시스템 탐색 화면을 제작한다.

## 01 패턴-사전

```text
ui-mockup. 디자인 패턴 사전과 shadcn처럼 소스 코드를 가져오는 디자인 시스템의 실제 탐색 화면을 그린다. 서비스 이름은 “디자인 사전”. 위 제목은 소개페이지 제목이 아니라 좌측상단 작은 제품명이다. 흰 바탕, 먹색 글자, 하늘색 선택면, 작은 레몬색 강조. 세로 가는 선으로 화면을 구분하는 정돈된 자료실 느낌. 화면 왼쪽 약15%는 사이드바: “시작하기”, “스타일”, “패턴 사전”(선택됨), “컴포넌트”, “아이콘”, “모듈”, “템플릿”. 그 아래 “탐색”, “입력”, “선택”, “피드백” 접기 가능한 분류. 상단은 넓은 검색창 “무엇을 만들고 싶나요?”와 오른쪽 작은 “AI용 정보” 링크. 중앙 약55%는 '패턴 사전' 제목, 목적칩 “찾기 / 비교하기 / 입력하기 / 복구하기”, 스타일 드롭다운 “다정한 선화”. 중앙은 큰 실제 UI 미리보기 2×2 그리드: “검색 결과 좁히기”(검색창+필터칩+결과2행), “입력 오류 고치기”(라벨있는 입력+오류+다시입력), “목록에서 상세 보기”(선택된 목록과상세패널), “변경 사항 확인하기”(두문서의차이와저장/취소). 그림은 인물삽화가 아니라 조작할모양과상태를정확히보여주는 UI미니어처. 카드의 이름과 짧은 ID를 아래에 둔다. 설명문단 없음. 검색 결과 좁히기 카드가 선택되어 테두리 강조. 오른쪽30% 상세패널 제목 “검색 결과 좁히기”, 작은 항목ID “DAT-02”, 더큰검색폼 미리보기, '구성 부품'에 “입력 · 선택 칩 · 결과 목록”. 그 아래 “React / HTML” 코드탭에서 HTML 선택, 선명한 예시 코드 <form class="ds-search"> / <input type="search" aria-label="검색"> / <button>검색</button> / </form> 을 짧은4줄로 표시. 최하단 눈에띄는 “코드 복사” 버튼과 보조 “파일 받기”. 필요파일 “search.html / search.css / search.svg”, 작은 상태 “구현 전”. UI가 찾기→미리보기→필요소스가져오기를 명확히 드러내야 한다.
공통 출력 조건: 가로 16:9 고해상도, 실제 웹 제품의 정면 스크린샷 한 장. 캔버스 전체가 제품 UI이며 바깥 시안 보드, 스마트폰, 브라우저 장식 테두리, 기울어진 화면, 푸터의 토큰샘플표를 만들지 않는다. 사람은 화면을 보고 패턴/부품을 찾고 소스를 가져오는 제품임을 즉시 알아야 한다. 한국어 텍스트와 코드가 작아 뭉개지지 않도록 콘텐츠 수를 적게 하고 읽을 수 있는 크기를 확보한다. 새브랜드·슬로건·캐릭터·생활앱·타이머·큰홍보제목은 넣지 않는다. 확정된 사용성검증이나 구현완료 배지와 가짜실적수치를 넣지 않는다. 최상단 작은 '시안' 배지를 넣어 이것이 설계 미리보기임을 표시한다. 코드 영역에는 '예시 코드'를 표시한다. 아름답고 단정한 한국어 편집과 여백, 실용적인 정보 밀도, 정확한 정렬, 일본 시각사전의 친절한 도해감. 보라색 SaaS 그라데이션 금지.
```

## 02 부품-라이브러리

```text

'필요한 항목' 토큰·CSS·아이콘의 명료한연결, '지원 형식'은 “React / HTML + CSS”와 작은 “설계 대상” 상태표시. 하단에 “관련 패턴”의 “저장 후 피드백”, “위험한 행동 확인”. 설치를강요하지않고 필요한코드와파일을고르는 소스라이브러리임이 드러나게. 장문의 API표·과도한샘플은 넣지 않는다.
공통 출력 조건: 가로 16:9 고해상도, 실제 웹 제품의 정면 스크린샷 한 장. 캔버스 전체가 제품 UI이며 바깥 시안 보드, 스마트폰, 브라우저 장식 테두리, 기울어진 화면, 푸터의 토큰샘플표를 만들지 않는다. 사람은 화면을 보고 패턴/부품을 찾고 소스를 가져오는 제품임을 즉시 알아야 한다. 한국어 텍스트와 코드가 작아 뭉개지지 않도록 콘텐츠 수를 적게 하고 읽을 수 있는 크기를 확보한다. 새브랜드·슬로건·캐릭터·생활앱·타이머·큰홍보제목은 넣지 않는다. 확정된 사용성검증이나 구현완료 배지와 가짜실적수치를 넣지 않는다. 최상단 작은 '시안' 배지를 넣어 이것이 설계 미리보기임을 표시한다. 코드 영역에는 '예시 코드'를 표시한다. 아름답고 단정한 한국어 편집과 여백, 실용적인 정보 밀도, 정확한 정렬, 일본 시각사전의 친절한 도해감. 보라색 SaaS 그라데이션 금지.
```
