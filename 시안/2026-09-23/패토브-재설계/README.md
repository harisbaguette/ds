# 패토브 / PATTOVE — 현재 검토안

일반 명사 ‘갈피’를 제외하고 이름·심벌·탐색·상세·비교·스타일·모바일을 다시 설계했다. **상황으로 찾고, 모양과 쓰임을 비교하고, 원하는 스타일로 저장하는 UI 패턴 사전**이다.

**[클릭 가능한 시안 열기](index.html)** · **[이미지 모아 보기](시안보기.html)** · [수정 근거](재설계-근거.md)

`index.html`을 브라우저로 열면 설치 없이 작동한다. 대표 패턴 16개와 스타일 3개의 흐름을 검토하는 시안이다. 전체 사전의 구현 완료를 뜻하지 않는다.

| 이전 문제 | 이번 수정 |
|---|---|
| 흔한 이름과 충돌 조사 부재 | 패토브 / PATTOVE로 교체, 영문·한글·앱·개발 서비스 1차 검색 기록 |
| 사전·책갈피 계열의 일반적인 로고 | 분리된 P와 선택을 나타내는 마름모, 실제 사용 가능한 SVG |
| 목적·기기·상태가 섞인 분류 | 목적별 탐색에 기기·상태 필터를 별도로 배치 |
| 이름을 알아야 찾을 수 있음 | 상황 검색과 바로 누를 수 있는 예시, 쉬운 한글 이름과 원래 명칭 병기 |
| 예시 속 버튼과 제품의 조작이 혼동됨 | 목록은 미리보기, 상세는 명시된 체험 영역, 실제 패턴 저장은 별도 버튼 |
| 설명을 읽어도 무엇을 골라야 할지 모름 | 사용 조건·피해야 할 상황·관련 패턴, 두 항목 나란히 비교 |
| 스타일이 삽화만 바꿈 | 같은 화면의 제목 서체·간격·색·선·버튼·표면을 함께 변경 |
| 모바일 카드가 지나치게 큼 | 작은 미리보기와 설명을 가로로 배치; 390×844 첫 화면에 카드 3개 전체 노출 |

## 확인한 범위

Playwright Chromium에서 **34개 검증 항목**을 통과했다. 상황 검색, 비교, 체험과 실제 저장의 분리, 저장 유지·취소, 검색 실패 복구, 모달 초점·Escape·Tab 순환, 탭 방향키, 입력 오류 복구, 단계 이동 후 값 유지, 움직임 완화 등을 확인했다. 320·390·768px 목록의 가로 넘침과 390px 상세를 확인했다. [실행 기록](검증-결과.json)과 [검증 스크립트](verify.cjs)를 보관한다.

검색은 로컬 별칭 색인이다. 저장은 이 브라우저에 한정된다. 실제 사용자 연구·실기기 터치·스크린리더·전체 WCAG 적합성 검증과 전체 사전 구현은 포함하지 않는다. 이름 검색도 상표권·도메인 확보 확인을 대신하지 않는다.

## 제작과 근거

- UI 이미지는 `index.html`을 실제 브라우저에서 캡처했다. 이미지에만 존재하는 검색·저장 버튼이 아니다.
- 브랜드 정본은 `brand.html`과 [SVG 심벌](assets/mark.svg)로 렌더했다. 브랜드 적용 이미지만 내장 `image_gen`을 사용했다. [실제 프롬프트](브랜드-생성-프롬프트.md)를 함께 보관한다.
- [10개 UI 스킬 적용 분석](<../../../문서/UI 스킬 적용 분석.md>)과 [레퍼런스 출처 대장](<../../../문서/레퍼런스 출처 대장.md>)을 현재 설계 기준으로 갱신했다.
- 이전 갈피·표본판·코드 화면 시안은 미채택 이력으로 보존했다. 원본 사전 66개와 영감 이미지 49개, 사용자의 디자인 시스템 정의 수정은 보존했다.
