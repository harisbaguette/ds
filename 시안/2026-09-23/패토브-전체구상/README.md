현재 로고·사전 구조·선화/컬러블록/풍경 기준을 바탕으로 내장 image_gen으로 제작한 정밀 구상 이미지다. 탐색에서 후보 선택, 상세 체험과 비교, 스타일 적용, 저장, 모바일 사용까지 이어진다. 부제·홍보 문구와 불필요한 설명은 제외한다.

| 이미지 | 보여주는 결정 |
|---|---|
| [01 패턴 탐색](01-패턴-탐색.png) | 짧은 이름과 큰 실물 미리보기로 찾는다. |
| [02 상황 검색](02-상황-검색과-선택.png) | 상황 검색으로 후보를 좁히고 두 항목을 선택한다. |
| [03 패턴 상세](03-패턴-상세.png) | 데모와 실제 패턴 저장을 구분하고 사용 조건을 확인한다. |
| [04 패턴 비교](04-패턴-비교.png) | 용도·확인·위치·피할 때를 나란히 비교한다. |
| [05 스타일 전체](05-스타일-전체.png) | 같은 기능에서 구도·서체·색·조작 형태의 차이를 본다. |
| [06 스타일의 입력과 피드백](06-스타일-입력과-피드백.png) | 선택한 스타일이 입력과 피드백까지 일관되게 이어진다. |
| [07 저장한 패턴](07-저장한-패턴.png) | 패턴과 스타일을 함께 저장해 다시 찾는다. |

이미지는 **설계 구상**이며, 동작 검증을 통과한 실제 브라우저 캡처와 구분한다. 대표 항목으로 전체 사용 흐름을 표현했으며 3,917개 사전 레코드의 전체 구현 완료를 뜻하지 않는다. 실제 로고의 형태·치수는 [기존 SVG](../패토브-재설계/assets/mark.svg)가 정본이다.
