## 01 탐색 시안

Use case: ui-mockup
Asset type: high-fidelity redesign concept for PATTOVE, a Korean style-based design system library.
Primary request: Draw a refined, lean desktop web interface screenshot (landscape 1440x1000 feel). The user chooses ONE style for an entire project, then finds reusable patterns inside that style. Reduce chrome so the pattern grid is the focal point.
Layout: 64px white top bar spans full width. At far left ONLY a small abstract cobalt P symbol, absolutely no wordmark. Beside it a short breadcrumb "스타일" / "선화" where 선화 is a quiet dropdown with tiny palette circles. At right a compact quiet search field "패턴 검색", then one discreet bookmark icon. Below top bar, a slim 168px white left sidebar with text-only category buttons "전체", "이동", "입력", "탐색", "피드백", "복구". Selected 전체 gets only a tiny cobalt indicator and medium weight; no large colored pill. Main area starts with a generous THREE-COLUMN GRID very close to the header, with no big heading, no summary text, no toolbar. 12 pattern cards total, show first 6 and part of next row. Each card has a warm off-white preview area of sophisticated black line UI (one cohesive ink style), short Korean name underneath, tiny optional bookmark. Show refined previews for toast, tabs, confirmation, progress, validation, empty state. Labels: "잠깐 알림", "탭", "확인창", "진행률", "입력 오류", "빈 상태".
Visual: professional Japanese minimalist catalog, disciplined typography, warm-gray preview surfaces, white chrome, restrained cobalt ONLY for selected global navigation. Hairline dividers, tiny radii, comfortable calibrated spacing, black thin-line icons. Typography small 13-16px in chrome, not oversized. Content occupies most of screen, chrome feels nearly invisible. No drop shadows except delicate preview depth. All 6 cards belong to SAME black-line style.
Constraints: no comparison feature, no list toggle, no sort control, no hero section, no logo text, no onboarding, no badges/count clutter, no marketing copy, no floating dock, no decorative illustrations in site chrome. The website shell is the work; do not invent extra product functions. Flat exact browser screenshot without device mockup, perspective, or surrounding presentation.

자체 비판: 선택한 스타일 안에 그리드를 곧바로 보여 주는 구조는 채택한다. 카드마다 외곽선을 둘러 반복되는 상자를 만든 점은 제외한다. 생성 로고는 기존 정본과 달라 적용하지 않는다. 내부 예시 문구와 기능 표현은 구현에 가져오지 않는다. 첫 진입에서 스타일 자체를 고르는 화면도 필요하다.

## 02 스타일 입구 시안

Use case: ui-mockup
Asset type: PATTOVE style library home, refined desktop website screenshot, landscape 1440x1000 feel.
Primary request: Design the lean FIRST screen: choose one visual style for an entire project. Make the three style families immediately legible through beautiful visual previews. Almost no website chrome.
Top bar 64px white, far left small standalone abstract cobalt P mark ONLY, a small 16px Korean page title "스타일" beside it, far right one discreet bookmark icon. No wordmark, search box, sidebar, hero, subtitle, large title, comparison, view toggles, sorting, buttons or feature descriptions on this overview.
Main area: three equally prominent style collection covers in one row, balanced margins, 28px gutters, start roughly y110. Each is a cohesive realistic focus-timer app sample in a different visual language. Left cover: white/offwhite, delicate black outlines, simple resting cat line illustration, refined black numerals "25:00", quiet rectangular "시작" action. Center: cobalt and acid lime graphic blocks, massive white "25:00", small round lime arrow button. Right: muted blue flat sea landscape, tiny sailboat and sun, charcoal "25:00", cream pill action. These are visual style covers, not functional embedded apps. No extra task lists under the timer, keep each cover around 480px high. One small caption BELOW each image: "선화", "컬러블록", "풍경"; a delicate right arrow at the far end of each caption. Optional three tiny palette dots beside each name. Whole cover is clickable, no separate 'apply' button or descriptions. No card outer borders, no shadows around covers, no nested boxes around the whole collection.
Professional Japanese visual catalog mood. Restrained white outer site surface. Airy but purposeful spacing, thin discreet separators only in top bar. Content is focal. Use small Korean type in chrome, no promotional text whatsoever. Flat exact browser screenshot, no tilted devices, no mockup background, no decorative giant brand name. Lower page simply white if needed; do not fill with invented features.

자체 비판: 세 스타일을 같은 크기의 표지로 보여 주는 구조는 채택한다. 원형 게이지·화분·사실적인 바위처럼 새로 생긴 내부 장식은 채택하지 않는다. 현재 범위는 사이트 외부다. 구현은 기존 스타일 표본의 상단 장면을 그대로 재사용하며, 새 내부 디자인을 만드는 것으로 시간을 쓰지 않는다.
