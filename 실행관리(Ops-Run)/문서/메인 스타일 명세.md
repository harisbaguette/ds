# 메인 프런트엔드 스타일

2026-09-26 · 0.3.0 · Trial

기존 익더·소프트 LCD·선화·루틴 격자·컬러블록·스티커·작은 정원·풍경·밤하늘은 목록, CSS, 레지스트리에서 제거했다. 사용자 요청에 따라 현재 메인 프런트엔드 스타일 하나를 구축한다. 시스템의 최종 목표는 [디자인 시스템 정의](<디자인 시스템 정의.md>)를 따른다.

## 레퍼런스 해석

이번 대화에서 사용자가 제공한 4장의 이미지가 근거다. 회색 바탕의 시계·물 마시기 위젯, 여러 뉴모픽 컨트롤을 모은 보드, 하트와 시계가 있는 모바일 화면, 둥근 음악·일정 대시보드를 직접 보고 해석했다. 원본 브랜드의 공식 설계나 실제 동작을 확인한 것은 아니다.

공통점은 밝은 회색 재질, 넓고 둥근 모서리, 양쪽 명암으로 만든 양각·음각, 작은 파스텔 포인트다. 투명도보다 뉴모픽 입체감이 중심이다. 메인 화면에서는 그 감각을 유지하고, 유리 표면은 떠 있는 탐색에 한정한다. 고양이·하트·날씨 같은 레퍼런스의 콘텐츠를 부품 사전에 장식으로 옮기지 않는다.

## 단점과 보완

| 확인한 문제 | 적용한 보완 |
|---|---|
| 밝은 회색 글자·컨트롤과 배경이 섞임 | 본문과 보조 글자는 짙게. 입력 경계·선택·초점은 대비가 있는 실선·채움으로 표시 |
| 모든 박스가 떠 있어 강조 순서를 알기 어려움 | 문서와 비교 시트는 그림자 없는 표면, 버튼은 작은 양각, 입력은 음각, 떠 있는 탐색만 유리 표면 |
| 눌림·선택·초점이 그림자로만 구분됨 | 눌림은 음각, 선택은 짙은 채움과 체크/현재 상태, 초점은 바깥 보라색 링 |
| 투명 배경과 흐림에 글자가 영향받음 | 본문은 불투명. 유리 표면은 높은 불투명도의 밝은 배경과 짙은 글자. 미지원·투명도 감소 설정에는 불투명 대체 |
| 비활성화가 흐린 정상 버튼처럼 보임 | 그림자 제거, 평평한 회색 채움, 실제 disabled 속성, 읽을 수 있는 라벨 유지 |
| 깊은 그림자와 큰 여백 때문에 작은 화면이 답답함 | 그림자 깊이 2단계, 44px 이상 조작 영역, 좁은 화면에서 한 열 조합. 비교 표만 내부 가로 스크롤 |
| 색만 보고 성공·실패를 추측해야 함 | 상태 이름, 체크·오류 기호, 접근성 상태 속성을 함께 제공 |

## 같은 기준을 적용하는 방법

공통 값의 정본은 `src/styles/themes.css`, 실제 HTML·React 부품의 공유 CSS는 `src/system/parts.css`다. 사이트 외곽은 `src/styles/atlas.css`에서 같은 `--p-*` 값을 사용한다. 보여 주기용 부품에만 숨은 스타일을 추가하지 않는다.

| 역할 | 값·규칙 |
|---|---|
| 바탕 / 표면 / 높은 표면 | #e9edf2 / #f1f3f6 / #fafbfc |
| 본문 / 보조 글자 | #2c333d / #59636f |
| 주요 행동 / 그 위의 글자 | #303b48 / #ffffff |
| 보조 색면 | #d3e8de. 의미 없는 강조색을 더 늘리지 않음 |
| 입력 경계 / 초점 | #7b8592 / #6153b5. 초점 링은 3px, 간격 3px |
| 오류 / 성공 / 주의 | #a3313e / #26614f / #805719. 짧은 상태 이름과 함께 사용 |
| 부품 / 표면의 모서리 | 16px / 24px. 큰 패널의 모서리를 작은 부품에 그대로 적용하지 않음 |
| 조작 높이 | 작은 44px / 기본 48px / 큰 56px |
| 움직임 | 140ms 색·그림자 전환. 움직임 감소 설정에서는 전환·회전 정지 |
| 타이포그래피 | 한글 Pretendard, 영문 표본 Outfit. 본문 16px, 보조 13px. 긴 한글은 줄바꿈 허용 |

본문 글자 대비 4.5:1, 입력·선택 등 의미 있는 비문자 경계 3:1을 검사 기준으로 사용한다. 배경 장식선이나 비활성 부품과 구분한다. 기준 출처: [W3C 글자 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [W3C 비문자 대비](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html). 일부 검사를 통과한 것을 WCAG 전체 준수로 표시하지 않는다.

## 적용 조건

차분한 개인 도구, 컬렉션·콘텐츠 보관함, 설정과 가벼운 작업 화면에 사용한다. 긴 문서나 많은 행의 표에서는 음각·양각을 셀마다 반복하지 않고 평면을 사용한다. 한 영역의 주요 행동은 하나를 우선하고 나머지는 보조 버튼·글자 버튼으로 낮춘다. 레퍼런스의 공기감 때문에 필요한 정보까지 숨기지 않는다.

재질은 `ds-surface`의 `data-material="raised|inset|glass"`로 참조할 수 있다. 버튼·필드·선택·탭·탐색·카드·검색 모듈의 예시는 동일한 CSS를 사용한다. React는 실제 컴포넌트, HTML은 조각·CSS·필요한 JavaScript를 제공한다.

이전 스타일 주소는 메인으로 이동하고 저장한 패턴의 식별자는 유지한다. 이전 스타일의 설치 URL은 제거되므로 새 설치는 `pattove-main-*`을 사용한다. 이미 다른 프로젝트로 가져간 파일은 자동 변경하지 않는다.

## 확인 범위

대표 부품의 상태, 검색·상세·보관·복귀, HTML 오프라인 사용과 별도 Next.js 프로젝트 설치를 검사한다. 작은 화면·키보드·움직임 감소·고대비를 포함한다. 결과와 전후 캡처는 `test-results/main-style/`에 기록한다. 전체 사전 구현, 모든 사용자 흐름, 실제 사용자의 이해도 검증은 별개다.
