# 모션과 AI용 코드 복사

상단 **모션**에서 실제 움직임을 보고 항목을 고른다. **사용 환경**을 HTML·React·Next.js 중에서 선택한다. **코드 복사**는 실행에 필요한 파일을, **AI용 정보 복사**는 코드와 함께 사전 ID·의존성·지원 조건·렌더링 비용·움직임 줄이기 대응을 전달한다.

HTML 코드는 파일로 저장해 열 수 있다. React는 컴포넌트와 CSS를 함께 사용한다. 조작이 필요한 예제는 `motion-runtime.js`도 함께 복사된다. Next.js는 Client Component와 페이지 연결 예시를 제공한다. 여러 React 인스턴스의 입력 ID와 라디오 그룹은 `useId`로 분리된다. HTML을 여러 번 붙일 때는 입력의 `id`, `for`, 라디오의 `name` 접두사를 각각 다르게 바꾸고 각 예제의 루트 요소에 실행 코드를 연결한다.

모션 상세의 관련 패턴을 누르면 사전 정의로 이동한다. 사전 상세의 **움직임 보기**에서는 연결된 실행 예제를 연다. 검색에는 한글·영문 이름과 `ANM-43` 같은 사전 ID를 사용할 수 있다.

드래그 정렬은 손잡이 또는 위아래 버튼으로 조작한다. 끌던 중 Escape로 취소할 수 있다. 대화상자는 Escape로 닫으며 원래 버튼으로 초점이 돌아온다. 저장 버튼은 성공·실패를 선택하는 예제다. 실제 제품에서는 요청 결과와 연결한다.

**일시정지**는 미리보기 전체에 적용된다. **움직임 줄여 보기**로 정적인 대체 표현을 확인할 수 있다. 운영체제에서 움직임 줄이기가 켜져 있으면 그 설정을 따른다. 스크롤 리빌은 지원 기능을 `@supports`로 확인하고, 미지원 환경에서는 정적 콘텐츠를 표시한다.

렌더링 비용의 낮음·중간·높음은 변경하는 CSS 속성과 효과 면적에 따른 예상이다. FPS 측정값이 아니다. 블러·그라데이션·3D 레이어는 실제 화면 크기와 기기에서 측정해야 한다. 반복 효과의 정지 조작은 유지하고, 소비 앱에서도 화면 밖·비활성 탭의 모션을 중지한다. [web.dev 성능 가이드](https://web.dev/articles/animations-guide), [MDN 움직임 줄이기](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion), [MDN 스크롤 타임라인](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-timeline).

## 가져다 쓸 레퍼런스

모션의 **외부 레퍼런스**에서 아래 사이트와 AI용 조사 조건을 함께 복사할 수 있다. 이 복사에는 외부 사이트의 실제 구현 코드는 포함되지 않는다.

| 레퍼런스 | 환경과 전달 방식 | 적용 전 확인 |
|---|---|---|
| [React Bits](https://github.com/DavidHDev/react-bits) | React, CSS/Tailwind 변형, 소스 복사·CLI | 항목별 의존성·WebGL·접근성, MIT + Commons Clause 조건 |
| [Magic UI](https://magicui.design/docs/mcp) | React·Next.js, Copy Page·MCP·설치 | 무료/Pro 구분, 개별 효과의 reduced-motion |
| [Motion](https://motion.dev/docs/react-accessibility) | React·JS·Vue, 문서·코드 복사 | `reducedMotion="user"`로도 opacity 등은 계속 움직일 수 있음 |
| [shadcn/ui](https://ui.shadcn.com/docs/mcp) | React·Next.js, 레지스트리·CLI·MCP | 파일·의존성 전달과 별도로 성능·접근성 검사 필요 |
| [Motion Lab](https://motion.luvisyouth.com) | HTML·CSS·JS, 전체 코드·AI 프롬프트 | 프롬프트의 조건이 실제 코드에 반영됐는지 확인 |
| [Effect.Labs](https://effect-labs.com/en/effects/backgrounds/aurora-mesh.html) | HTML·CSS·JS, 데모·코드·지원 조건 | 오로라 예제는 reduced-motion 처리를 추가해야 함 |
| [Animate.css](https://animate.style) | CSS 클래스·시간 변수, 코드·설치 | reduced-motion 지원, 번들 크기·반복 사용 범위 |
| [Animista](https://animista.net) | CSS 미리보기·설정·코드 생성 | 브라우저 fallback·reduced-motion 조건을 별도로 추가 |

[참고 게시물과 영상](https://x.com/kawai_design/status/2105417404339937585)은 Animation Dictionary의 검색·분류, 실물 카드, CSS/HTML/AI 탭, 일시정지와 상세 사양을 보여 준다. 게시물은 사이트 주소를 DM으로 제공한다고 안내하며 공개 원문에 주소는 없다. 위 외부 사이트는 별도로 조사한 레퍼런스다.
