# 1. 스타일을 구성하는 공통 기준

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 1번 분류 VIS다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

이 항목들은 각 스타일이 채워야 할 공통 정의다. 색상표만 바꾼 테마를 별도 패턴으로 늘리지 않는다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| VIS-01 | 의미별 색상 — Semantic Colors | 기준 | 배경·본문·강조·상태를 구분 | 확인 [D] |
| VIS-02 | 글꼴과 글자 위계 — Typography Scale | 기준 | 제목·본문·보조 정보의 관계 | 확인 [D] |
| VIS-03 | 한글·영문 혼용 조판 | 기준 | 문자별 크기·행간·줄바꿈을 조정 | 확장 [D] |
| VIS-04 | 여백과 세로 리듬 — Spacing Rhythm | 기준 | 관련 정보의 묶음과 구간을 표현 | 확인 [D] |
| VIS-05 | 콘텐츠 너비와 그리드 | 기준 | 읽기와 배치의 공통 골격 | 확인 [D] |
| VIS-06 | 선·모서리·그림자·깊이 | 기준 | 경계와 요소 간 앞뒤 관계 | 확인 [D] |
| VIS-07 | 아이콘 체계 | 기준 | 선·크기·의미·문자와의 정렬 | 확인 [D] |
| VIS-08 | 이미지 비율·크롭·캡션 | 기준 | 같은 시각 자료의 일관된 배치 | 확장 [R] |
| VIS-09 | 사진·일러스트·질감의 표현 방향 | 기준 | 시각 자료를 스타일에 맞게 선택 | 확장 [V] |
| VIS-10 | 강조의 강약과 정보 밀도 | 기준 | 모든 요소가 경쟁하지 않게 조절 | 확장 [R] |
| VIS-11 | 밝은·어두운 테마 대응 | 기준 | 같은 의미와 위계를 환경별로 유지 | 확인 [V] |
| VIS-12 | 반응형 전환 기준 | 기준 | 공간 변화에 따른 재배치·축약 | 확인 [K] |
| VIS-13 | 움직임의 목적과 강도 | 기준 | 피드백·연결·전환의 공통 원칙 | 확인 [E] |
| VIS-14 | 제품 문구와 용어의 일관성 | 기준 | 버튼·오류·안내의 말투와 의미 | 확인 [W] |
| VIS-15 | 상호작용 상태 단계 — Interaction States | 기준 | 기본·올림·초점·눌림·비활성·선택의 표현 순서 | 확장 [MK] |
| VIS-16 | 터치·클릭 목표 크기 | 기준 | 손가락·포인터가 놓치지 않는 최소 크기와 간격 | 확장 [MK] |
| VIS-17 | 층위·겹침 순서 규칙 — Elevation / Layering | 기준 | 툴팁·메뉴·대화상자가 겹칠 때의 위아래 순서 | 확장 [MK] |
| VIS-18 | 로고·브랜드 자산 사용 규칙 | 기준 | 여백·최소 크기·배경별 변형의 허용 범위 | 확장 [MK] |
