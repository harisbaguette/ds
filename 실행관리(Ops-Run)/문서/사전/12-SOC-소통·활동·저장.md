# 12. 소통·활동·저장

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 12번 분류 SOC다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

소통 기능이 있는 제품에서 선택하는 항목이다. 일반 웹사이트의 기본 구성에는 자동 추가하지 않는다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| SOC-01 | 사용자 표시 — Avatar / Identity | 부품 | 작성자·참여자 식별 | 확인 [S] |
| SOC-02 | 활동 내역 — Activity Stream | 모듈 | 변화와 진행 맥락을 시간순으로 확인 | 확인 [US] |
| SOC-03 | 댓글과 답글 — Comment Thread | 모듈 | 주제에 대한 대화 연결 | 확인 [K] |
| SOC-04 | 채팅 — Chat | 모듈 | 메시지 입력·수신·상태 표시 | 확인 [US] |
| SOC-05 | 반응 — Reactions | 부품 | 콘텐츠에 짧은 반응 표현 | 확인 [US] |
| SOC-06 | 저장·북마크 — Favorites | 구성 | 다시 볼 콘텐츠를 보관 | 확인 [UN] |
| SOC-07 | 신고·차단 — Report / Block | 구성 | 문제를 알리고 접촉을 제한 | 확장 [US] |
| SOC-08 | 알림 모음과 읽음 상태 | 모듈 | 놓친 활동을 확인하고 이동 | 확장 [UN] |
| SOC-09 | 팔로우·구독 관계 | 구성 | 따르기·끊기와 알림 켜기 | 확장 [MK] |
| SOC-10 | 멘션·태그로 사람 부르기 | 구성 | @이름 입력과 알림 | 확장 [MK] |
| SOC-11 | 공유 시트·공유 링크 만들기 | 구성 | 외부·내부로 내보내는 공유 선택 | 확장 [MK] |
| SOC-12 | 게시물 작성기 — Composer | 모듈 | 글·사진·설문을 올리는 입력 창 | 확장 [MK] |
| SOC-13 | 스레드·인용 게시 | 구성 | 이어 쓰기와 인용해서 쓰기 | 확장 [MK] |
| SOC-14 | 추천 피드·팔로잉 피드 전환 | 구성 | 알고리즘 순과 시간순 고르기 | 확장 [MK] |
| SOC-15 | 투표·설문 게시물 | 부품 | 게시물 안 선택지와 결과 | 확장 [MK] |
| SOC-16 | 스토리·24시간 게시물 | 모듈 | 짧게 사라지는 세로 콘텐츠 넘기기 | 확장 [MK] |
| SOC-17 | 라이브 방송·채팅 참여 | 모듈 | 실시간 영상과 채팅·후원 | 확장 [MK] |
| SOC-18 | 그룹·커뮤니티 공간 | 모듈 | 가입·규칙·게시판이 있는 모임 | 확장 [MK] |
| SOC-19 | 프로필 페이지 — 공개 활동 | 모듈 | 소개·게시물·팔로워 수 | 확장 [MK] |
