# 15. 검색과 발견의 세부 패턴

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 15번 분류 SRH다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| SRH-01 | 검색 결과의 일치 부분 강조 | 구성 | 검색어와 결과의 관계 설명 | 확인 [ALG] |
| SRH-02 | 검색 결과의 문맥 요약 | 구성 | 이동 전에 관련 내용 판별 | 확인 [ALG] |
| SRH-03 | 분류를 따라 좁히는 검색 | 구성 | 상위·하위 분류로 결과 제한 | 확인 [ALG] |
| SRH-04 | 음성으로 검색어 입력 | 구성 | 타이핑 없이 검색 | 확인 [ALG] |
| SRH-05 | 입력 오류 제안·교정 | 구성 | 잘못 적은 검색어에서 복구 | 확장 [UXP] |
| SRH-06 | 검색 결과 없음의 대안 탐색 | 구성 | 조건을 풀거나 다른 표현 제안 | 확장 [UXP] |
| SRH-07 | 범주별 통합 검색 결과 | 모듈 | 문서·사람·상품 결과를 구분 | 확장 [ALG] |
| SRH-08 | 최근 검색·개별 삭제 | 모듈 | 이전 검색을 재사용·관리 | 확장 [UXP] |
| SRH-09 | 검색 범위 선택 | 구성 | 전체·현재 폴더 등 대상을 지정 | 확장 [UXP] |
| SRH-10 | 검색 조건의 주소 공유 | 구성 | 동일한 결과 조건을 재현 | 확인 [CF] |
| SRH-11 | 조건별 결과 수 표시 | 구성 | 좁히기 전 선택 효과 확인 | 확장 [ALG] |
| SRH-12 | 즉시 적용과 일괄 적용 선택 | 기준 | 조회 비용·모바일 공간에 맞춰 적용 | 확장 [CAR] |
| SRH-13 | 필터 안에서 값 검색 | 구성 | 매우 많은 속성 값 중 선택 | 확장 [ALG] |
| SRH-14 | 추천 근거와 관심 없음 | 구성 | 개인화 이유를 이해하고 수정 | 확장 [AISH] |
| SRH-15 | 이미지로 비슷한 대상 찾기 | 모듈 | 시각적 속성으로 탐색 시작 | 확장 [ALG] |
| SRH-16 | 고급 검색 구문 도움말 | 모듈 | 반복 작업용 검색식 작성 | 확장 [PAP] |
| SRH-17 | 저장 검색의 결과 알림 | 흐름 | 조건 저장 → 새 결과 알림 → 확인 | 확장 · 기능 사이트 요구 |
| SRH-18 | 탐색 경로·최근 대상 기록 | 모듈 | 검색과 이동 과정으로 되돌아가기 | 확장 · 웹앱 요구 |
| SRH-19 | 검색어 자동완성의 최근·인기 구분 | 구성 | 내 기록과 남들 인기 제안을 나눠 보임 | 확장 [MK] |
| SRH-20 | 검색 결과 정렬의 관련도·최신 전환 | 구성 | 정확도 순과 최신 순을 고르기 | 확장 [MK] |
| SRH-21 | 결과 안 즉시 답 — Answer Box | 구성 | 계산·정의처럼 결과 위에 바로 답 표시 | 확장 [MK] |
| SRH-22 | 필터 조건 저장·이름 붙이기 | 구성 | 자주 쓰는 조건에 이름을 붙여 보관 | 확장 [MK] |
| SRH-23 | 검색 결과의 그룹 묶기 | 구성 | 같은 대상의 여러 결과를 한 묶음으로 | 확장 [MK] |
| SRH-24 | 검색 중 결과 미리 갱신 — Type-ahead Results | 구성 | 입력할 때마다 결과가 바뀜 | 확장 [MK] |
| SRH-25 | 문서 안 찾기 — Find in Page | 구성 | 현재 화면 안에서만 단어 찾기 | 확장 [MK] |
| SRH-26 | 검색 결과 위치 표시·다음 결과 이동 | 구성 | 몇 번째 결과인지와 다음으로 이동 | 확장 [MK] |
| SRH-27 | 동의어·오타 허용 검색 안내 | 구성 | "~로 검색했습니다" 표시와 원래대로 | 확장 [MK] |
| SRH-28 | 검색 결과의 시각 요약 — 카드형 결과 | 구성 | 사진·가격·평점을 카드로 | 확장 [MK] |
| SRH-29 | 바코드·이미지·음성 통합 검색 입구 | 구성 | 글자 외 입력을 검색창에 함께 | 확장 [MK] |
| SRH-30 | 검색 광고·후원 결과 표시 | 구성 | 광고 결과를 구분해 표시 | 확장 [MK] |
| SRH-31 | 탐색 유도 — 주제 둘러보기 | 모듈 | 검색어 없이 분류·추천으로 돌아다니기 | 확장 [MK] |
| SRH-32 | 검색 결과 새로 고침 없이 필터 갱신 | 구성 | 조건 바꿔도 화면이 튀지 않게 | 확장 [MK] |
| SRH-33 | 검색 기록 끄기·비공개 검색 | 구성 | 기록 남기지 않고 검색 | 확장 [MK] |
| SRH-34 | 검색 탭 모핑 — Tab(role: .search) | 구성 | 탭바의 검색 탭을 누르면 그 자리가 검색 입력창으로 바로 바뀜 | 확인 [LGR] |
