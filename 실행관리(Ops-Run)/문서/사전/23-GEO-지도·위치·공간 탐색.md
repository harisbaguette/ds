# 23. 지도·위치·공간 탐색

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 23번 분류 GEO다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

| ID | 항목 | 통용 용어 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|---|
| GEO-01 | 지도 마커와 정보 팝업 | 지도 마커 팝업 (Map Marker Popup) | 구성 | 장소와 해당 정보를 연결 | 확인 [LEAF] |
| GEO-02 | 현재 위치와 정확도 표시 | 현재 위치 표시 (Current Location Indicator) | 구성 | 사용자 기준점을 지도에 표현 | 확장 [LEAF] |
| GEO-03 | 위치 검색과 지도 이동 | 장소 검색 (Location Search) | 모듈 | 장소 이름에서 위치 탐색 | 확장 [ALG] |
| GEO-04 | 지도와 결과 목록 동기화 | 지도·목록 연동 (Map List View) | 모듈 | 공간·텍스트 탐색을 연결 | 확장 [ALG] |
| GEO-05 | 겹친 마커 묶기 — Clustering | 마커 클러스터링 (Marker Clustering) | 구성 | 밀집 위치를 단계별로 탐색 | 확장 [LEAF] |
| GEO-06 | 현재 지도 영역 재검색 | 이 지역 재검색 (Search This Area) | 구성 | 이동한 영역을 새 탐색 조건으로 사용 | 확장 [ALG] |
| GEO-07 | 지도 레이어 전환 | 레이어 전환 (Layer Switcher) | 모듈 | 서로 다른 공간 정보 비교 | 확인 [LEAF] |
| GEO-08 | 경로·경유지 편집 | 경유지 편집 (Waypoint Editor) | 모듈 | 이동 순서와 위치 조정 | 확장 [ORB] |
| GEO-09 | 이동 수단별 경로 비교 | 경로 비교 (Route Comparison) | 모듈 | 소요 시간·거리·조건 비교 | 확장 [ORB] |
| GEO-10 | 반경·영역 선택 검색 | 반경 검색 (Radius Search) | 구성 | 공간 범위로 대상 제한 | 확장 [LEAF] |
| GEO-11 | 실내 평면도·비지리 지도 | 실내 지도 (Indoor Map) | 모듈 | 건물·시설 내부 위치 탐색 | 확인 [LEAF] |
| GEO-12 | 지도 기호·척도·범례 | 지도 범례 (Map Legend) | 구성 | 시각 기호와 거리의 의미 설명 | 확장 [LEAF] |
| GEO-13 | 위치 접근 거절 후 수동 선택 | 수동 위치 입력 (Manual Location Entry) | 구성 | 권한 없이도 목적지 입력 | 확장 [LEAF] |
| GEO-14 | 지도 대신 주소·목록 이용 | 목록 보기 대안 (List View Alternative) | 구성 | 지도를 조작하기 어려운 경우 대안 | 확인 [LEAF] |
| GEO-15 | 360도 공간·핫스폿 탐색 | 360도 뷰 (360 Panorama Viewer) | 모듈 | 시야를 돌려 장소의 상세 확인 | 확인 [HFP] |
| GEO-16 | 지도에서 위치 찍어 입력 | 핀 드롭 (Drop Pin) | 구성 | 핀을 놓아 주소·좌표 채우기 | 확장 [MK] |
| GEO-17 | 실시간 위치 추적 지도 | 실시간 위치 추적 (Live Location Tracking) | 구성 | 움직이는 차량·사람을 지도에 | 확장 [MK] |
| GEO-18 | 턴바이턴 길 안내 | 턴바이턴 내비게이션 (Turn-by-Turn Navigation) | 흐름 | 다음 꺾을 곳을 순서대로 | 확장 [MK] |
| GEO-19 | 지도 스타일 — 위성·지형·다크 | 지도 유형 선택 (Map Type Selector) | 구성 | 바탕 지도 종류 고르기 | 확장 [MK] |
| GEO-20 | 지도 위 히트맵 | 히트맵 (Heatmap) | 구성 | 밀집 정도를 색으로 | 확장 [MK] |
| GEO-21 | 지도 그리기 — 영역·선 편집 | 지도 그리기 도구 (Map Drawing Tools) | 구성 | 구역·경로를 직접 그림 | 확장 [MK] |
| GEO-22 | 장소 카드·상세 시트 | 장소 상세 시트 (Place Details Sheet) | 구성 | 마커 누르면 아래에서 올라오는 상세 | 확장 [MK] |
| GEO-23 | 거리·면적 측정 도구 | 거리 측정 (Measure Distance) | 구성 | 지도 위 두 점 거리 재기 | 확장 [MK] |
| GEO-24 | 주변 탐색 — 근처 카테고리 | 주변 검색 (Nearby Search) | 구성 | 근처 카페·주유소 빠른 버튼 | 확장 [MK] |
| GEO-25 | 오프라인 지도 다운로드 | 오프라인 지도 (Offline Maps) | 구성 | 지역 지도를 미리 받아 두기 | 확장 [MK] |
| GEO-26 | 지오펜스·도착 알림 | 지오펜싱 (Geofencing) | 구성 | 특정 구역에 들어오면 알림 | 확장 [MK] |
| GEO-27 | 주소 정규화·후보 선택 | 주소 자동완성 (Address Autocomplete) | 구성 | 애매한 주소를 후보 중 고르기 | 확장 [MK] |
| GEO-28 | 위치 공유·만남 장소 | 위치 공유 (Location Sharing) | 구성 | 내 위치를 잠시 보내기 | 확장 [MK] |
| GEO-29 | 층별 실내 지도 전환 | 층 선택기 (Floor Picker) | 구성 | 건물 안 층 고르기 | 확장 [MK] |
| GEO-30 | 지도 접근성 — 목록·키보드 이동 | 접근 가능한 지도 (Accessible Map) | 구성 | 마우스 없이 지도 대상 탐색 | 확장 [MK] |
