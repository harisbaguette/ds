# 26. 고객지원과 문제 해결

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 26번 분류 HLP다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

| ID | 항목 | 통용 용어 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|---|
| HLP-01 | 도움말 검색·주제 탐색 | 헬프 센터 검색 (Help Center Search) | 모듈 | 문제에 맞는 안내 찾기 | 확장 [SHR] |
| HLP-02 | 현재 작업에 맞는 도움 패널 | 도움말 패널 (Help Panel) | 모듈 | 화면을 떠나지 않고 설명 확인 | 확인 [CF] |
| HLP-03 | 문제 진단 질문 흐름 | 문제 해결 마법사 (Troubleshooting Wizard) | 흐름 | 증상 선택 → 조건 확인 → 해결법 | 확장 [HFP] |
| HLP-04 | 지원 문의 접수 | 문의 양식 (Contact Support Form) | 모듈 | 문제·환경·자료를 묶어 제출 | 확장 · 고객지원 요구 |
| HLP-05 | 문의 상태와 담당자 | 티켓 상태 (Ticket Status) | 모듈 | 응답·처리 진행을 추적 | 확장 · 고객지원 요구 |
| HLP-06 | 지원 대화의 상담원 인계 | 상담원 연결 (Human Handoff) | 흐름 | 자동 안내 → 맥락 전달 → 사람 연결 | 확장 · 고객지원 요구 |
| HLP-07 | 서비스 장애 공지와 구독 | 상태 페이지 (Status Page) | 모듈 | 장애 영향·복구 상황을 확인 | 확장 [CF] · 대조 [ATLCOMP] |
| HLP-08 | 문서 유용성 피드백 | 문서 피드백 (Was This Helpful) | 구성 | 해결 여부와 부족한 내용을 수집 | 확인 [CF] |
| HLP-09 | 재현 절차·진단 자료 첨부 | 진단 정보 첨부 (Diagnostic Report) | 모듈 | 문제를 재현할 정보를 정리 | 확장 · 고객지원 요구 |
| HLP-10 | 도움말과 제품 버전 연결 | 버전별 문서 (Versioned Docs) | 구성 | 현재 환경에 맞는 안내 선택 | 확장 · 기술 문서 요구 |
| HLP-11 | 챗봇 첫 인사·빠른 선택지 | 챗봇 웰컴 메시지 (Welcome Message) | 구성 | 자주 묻는 것을 버튼으로 | 확장 [MK] |
| HLP-12 | 문서 안 단계별 가이드 — 걸어가며 보기 | 인터랙티브 워크스루 (Interactive Walkthrough) | 구성 | 실제 화면에서 다음 클릭 자리 표시 | 확장 [MK] |
| HLP-13 | 키보드 단축키 안내 창 | 단축키 도움말 (Keyboard Shortcuts Dialog) | 부품 | ? 키로 열리는 단축키 목록 | 확장 [MK] |
| HLP-14 | 빈 화면 도움 링크·영상 | 빈 상태 도움말 (Empty State Help) | 구성 | 처음 화면에 배우는 자료 연결 | 확장 [MK] |
| HLP-15 | 지원 시간·응답 예상 시간 | 예상 응답 시간 (Expected Response Time) | 부품 | 언제 답이 오는지 알려 줌 | 확장 [MK] · 대조 [ZDSLA] |
| HLP-16 | 커뮤니티 질문·답변 | 커뮤니티 포럼 (Community Forum) | 모듈 | 사용자끼리 묻고 답하기 | 확장 [MK] |
| HLP-17 | 기능 요청·투표 | 기능 요청 보드 (Feature Request Board) | 모듈 | 원하는 기능을 올리고 투표 | 확장 [MK] |
| HLP-18 | 버그 신고·스크린샷 자동 첨부 | 버그 리포트 (Bug Report) | 구성 | 화면 잡아 신고에 붙이기 | 확장 [MK] |
| HLP-19 | 도움말 언어 전환 | 언어 선택 (Language Switcher) | 구성 | 문서 언어 고르기 | 확장 [MK] |
| HLP-20 | 알려진 문제 목록 | 알려진 이슈 (Known Issues) | 모듈 | 지금 아는 문제와 우회 방법 | 확장 [MK] |
| HLP-21 | 릴리즈 노트 안 도움말 연결 | 릴리스 노트 (Release Notes) | 구성 | 바뀐 기능의 설명으로 이동 | 확장 [MK] |
| HLP-22 | 사용자 피드백 설문 — NPS·만족도 | NPS 설문 (NPS Survey) | 구성 | 짧은 점수 설문 | 확장 [MK] |
| HLP-23 | 푸터 도움말 — Footer Help | 푸터 도움말 (Footer Help) | 모듈 | 페이지 맨 아래 고정으로 두는 문의·도움말 안내 | 확인 [G] |
| HLP-24 | 문맥 도움말 — Contextual Help | 문맥 도움말 (Contextual Help) | 부품 | 지금 보는 화면·항목에 딱 맞춰 옆이나 안에 바로 띄우는 도움말 | 확인 [CHKUI] |
| HLP-25 | 해결 후 자동 만족도 설문 | CSAT 설문 (CSAT Survey) | 흐름 | 문의가 끝나면 점수를 물음 | 확인 [ZDCSAT] |
| HLP-26 | 기능별 서비스 상태 격자 | 서비스 상태 표 (Component Status) | 구성 | 어느 기능이 지금 아픈지 표로 | 확인 [ATLCOMP] |
| HLP-27 | 장애 처리 4단계 표시 | 장애 상태 단계 (Incident Status) | 흐름 | 조사중→원인파악→확인중→해결됨 | 확인 [ATLINC] |
| HLP-28 | 규칙 기반 티켓 자동 처리 | 티켓 자동화 (Ticket Automation) | 모듈 | 조건에 맞으면 알아서 배정·회신 | 확인 [ICWORKFL] |
