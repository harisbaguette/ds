# 28. 모바일 시스템과 기기 기능

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 28번 분류 MOB다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

| ID | 항목 | 통용 용어 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|---|
| MOB-01 | 화면 키보드와 입력 영역 이동 | 키보드 회피 (Keyboard Avoidance) | 구성 | 입력·제출이 키보드에 가리지 않게 유지 | 확장 [ADAPT] |
| MOB-02 | 안전 영역·기기 가장자리 배치 | 세이프 에어리어 (Safe Area) | 기준 | 시스템 영역과 조작 영역 분리 | 확장 [HIGLAY] |
| MOB-03 | 뒤로 가기와 상태 보존 | 뒤로 가기 상태 유지 (Back Navigation State) | 구성 | 이전 화면의 작업으로 자연스럽게 복귀 | 확인 [MOBILE] |
| MOB-04 | 한 화면·두 화면 전환 | 리스트·디테일 레이아웃 (List-Detail Layout) | 구성 | 가용 폭에 따라 목록·상세 재배치 | 확인 [ADAPT] |
| MOB-05 | 시스템 공유·앱으로 전달 | 공유 시트 (Share Sheet) | 모듈 | 콘텐츠를 다른 앱의 작업으로 연결 | 확장 · 모바일 앱 요구 |
| MOB-06 | 외부 링크에서 특정 화면 열기 | 딥 링크 (Deep Link) | 흐름 | 외부 진입 → 대상 확인 → 앱 탐색 | 확장 · 모바일 앱 요구 |
| MOB-07 | 사진·카메라 자료 선택 | 사진 선택기 (Photo Picker) | 모듈 | 촬영과 저장 자료를 입력으로 사용 | 확장 · 모바일 앱 요구 |
| MOB-08 | QR·바코드 스캔 | QR·바코드 스캐너 (QR Code Scanner) | 모듈 | 인식 영역·결과·재시도 연결 | 확장 [SYNC] |
| MOB-09 | 음성 녹음과 입력 레벨 | 음성 녹음기 (Audio Recorder) | 모듈 | 녹음 상태·길이·재녹음 제어 | 확인 [HFP] |
| MOB-10 | 권한 요청의 맥락과 대안 | 권한 요청 플로우 (Permission Request Flow) | 흐름 | 기능 시작 → 권한 → 허용·거절 대안 | 확장 [HIGPR] |
| MOB-11 | 알림 진입과 읽음 동기화 | 알림 딥 링크 (Notification Deep Link) | 흐름 | 알림 → 관련 화면 → 상태 갱신 | 확장 · 모바일 앱 요구 |
| MOB-12 | 촉각 피드백의 목적별 대응 | 햅틱 피드백 (Haptic Feedback) | 기준 | 성공·경고·조작을 촉각으로 보조 | 확장 · 모바일 앱 요구 |
| MOB-13 | 백그라운드 복귀와 재동기화 | 포그라운드 복귀 동기화 (Foreground Refresh) | 구성 | 중단된 작업의 최신 상태 확인 | 확장 · 모바일 앱 요구 |
| MOB-14 | 오프라인 보관과 다운로드 관리 | 오프라인 다운로드 (Offline Downloads) | 모듈 | 나중에 볼 자료와 용량 관리 | 확장 · 모바일 앱 요구 |
| MOB-15 | 시스템 라이브 활동 | 라이브 액티비티 (Live Activities) | 모듈 | 앱 밖에서 진행 중 상태 확인 | 확장 [HIGLIVE] |
| MOB-16 | 앱 설치·업데이트 안내 | 앱 업데이트 안내 (App Update Prompt) | 구성 | 계속 사용 가능한 경로 안내 | 확장 · 웹앱·모바일 앱 요구 |
| MOB-17 | 생체 인증의 대체 경로 | 생체 인증 대체 (Biometric Fallback) | 구성 | 기기 인증 실패 후 접근 복구 | 확장 · 모바일 앱 요구 |
| MOB-18 | 한 손 조작과 도달 영역 | 엄지 영역 (Thumb Zone) | 기준 | 주요 행동 위치를 사용 환경에 맞춤 | 확장 [HIGGEST] |
| MOB-19 | 회전·분할 화면의 작업 유지 | 화면 회전 대응 (Orientation Change) | 구성 | 화면 환경이 변해도 과제 지속 | 확장 [ADAPT] |
| MOB-20 | 장치 연결·연결 해제 | 기기 페어링 (Device Pairing) | 모듈 | 주변 기기 탐색·선택·연결 상태 | 확장 · 기기 연동 앱 요구 |
| MOB-21 | 위젯·홈 화면 정보 | 홈 화면 위젯 (Home Screen Widget) | 구성 | 앱 밖에서 보이는 작은 정보 조각 | 확장 [MK] |
| MOB-22 | 잠금 화면·알림 액션 | 알림 액션 (Actionable Notification) | 구성 | 알림에서 바로 답하기·완료하기 | 확장 [MK] |
| MOB-23 | 앱 클립·인스턴트 앱 | 앱 클립 (App Clip) | 구성 | 설치 없이 일부 기능 바로 | 확장 [MK] |
| MOB-24 | NFC·근거리 태그 읽기 | NFC 태그 (NFC Tag Reading) | 구성 | 태그에 대면 열리는 기능 | 확장 [MK] |
| MOB-25 | 지문·얼굴 인증 진입 | 생체 인증 (Biometric Authentication) | 구성 | 생체 인증으로 잠금 풀기 | 확장 [MK] |
| MOB-26 | 앱 평가 요청 시점 | 앱 평점 요청 (App Rating Prompt) | 구성 | 좋은 순간에 평점 요청 | 확장 [MK] |
| MOB-27 | 앱 아이콘 배지·미읽음 | 앱 아이콘 배지 (App Icon Badge) | 부품 | 아이콘 위 숫자 | 확장 [MK] |
| MOB-28 | 다크 모드 자동 전환 | 다크 모드 (Dark Mode) | 구성 | 시스템 설정 따라 바뀜 | 확장 [MK] |
| MOB-29 | 글자 크기 시스템 설정 반영 | 다이내믹 타입 (Dynamic Type) | 구성 | 기기 글자 크기에 따라 커짐 | 확장 [MK] |
| MOB-30 | 앱 내 브라우저·외부 열기 | 인앱 브라우저 (In-App Browser) | 구성 | 링크를 안에서 볼지 밖에서 볼지 | 확장 [MK] |
| MOB-31 | 클립보드 감지·붙여넣기 제안 | 클립보드 붙여넣기 제안 (Paste Suggestion) | 구성 | 복사한 링크·코드를 바로 제안 | 확장 [MK] |
| MOB-32 | 푸시 알림 권한 요청 시점 | 푸시 권한 요청 (Push Permission Prompt) | 구성 | 필요한 순간에 허용 요청 | 확장 [MK] |
| MOB-33 | 앱 시작 화면·스플래시 | 스플래시 화면 (Splash Screen) | 부품 | 첫 로딩 동안 보이는 화면 | 확장 [MK] |
| MOB-34 | 탭 다시 눌러 맨 위·새로고침 | 탭 눌러 맨 위로 (Tap to Scroll to Top) | 구성 | 현재 탭을 또 누르면 위로 | 확장 [MK] |
| MOB-35 | 사진 저장·앨범 권한 | 사진 저장 권한 (Photo Library Permission) | 구성 | 결과를 기기에 저장 | 확장 [MK] |
| MOB-36 | 공유 확장·다른 앱에서 받기 | 공유 확장 (Share Extension) | 구성 | 다른 앱의 공유 목록에 뜨기 | 확장 [MK] |
| MOB-37 | 전화·문자·이메일 바로 연결 | 전화 링크 (Tap to Call) | 구성 | 번호 누르면 전화 걸기 | 확장 [MK] |
| MOB-38 | 기기 방향 잠금·가로 전용 화면 | 화면 방향 고정 (Orientation Lock) | 구성 | 영상·게임의 가로 고정 | 확장 [MK] |
| MOB-39 | 배터리 절약·저전력 대응 | 저전력 모드 대응 (Low Power Mode) | 구성 | 저전력일 때 줄이는 동작 | 확장 [MK] |
| MOB-40 | 워치·보조 기기 화면 | 워치 앱 (Watch App) | 구성 | 손목 시계 등 작은 화면 요약 | 확장 [MK] |
| MOB-41 | 인앱 내장 포토 피커 — Embedded Photo Picker | 임베디드 포토 피커 (Embedded Photo Picker) | 부품 | 앱을 벗어나지 않고 그 안에서 바로 여는 시스템 사진 선택기 | 확인 [AND16] |
| MOB-42 | 파형 지정 햅틱 — Custom Haptic Waveform | 커스텀 햅틱 (Custom Haptics) | 부품 | 정해진 패턴이 아니라 직접 그린 파형으로 만드는 진동 피드백 | 확인 [AND16] |
| MOB-43 | 앱 안 웹 화면 — WebView / In-app Browser | 웹뷰 (WebView) | 구성 | 앱을 떠나지 않고 웹 페이지를 앱 안에서 여는 화면. 뒤로·앞으로 이동과 "브라우저에서 열기"를 함께 두고, 앱이 브라우저 흉내를 내지 않도록 함 | 확인 [RCAPLWV] |
