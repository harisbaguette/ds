# 41. 게임·인터랙티브 화면 요소

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 41번 분류 GAM다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

게임과 게임처럼 움직이는 화면의 골격, 여러 게임이 함께 쓰는 공통 화면, 첫 실행부터 종료까지 이어지는 흐름을 담는다. 플레이 중 화면 위 표시, 상점·재화·확률, 라이브 운영·소셜, 장르 고유 화면, 입력·플랫폼 적응, 감각 연출, 엔진 구현, 게임 접근성은 67~74번 분류에서 다룬다. 재미 요소를 업무 화면에 그대로 옮기지 않으며, 점수·보상은 실제 행동과 연결될 때만 쓴다.
