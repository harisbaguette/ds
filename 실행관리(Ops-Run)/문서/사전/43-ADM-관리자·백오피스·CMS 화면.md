# 43. 관리자·백오피스·CMS 화면

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 43번 분류 ADM다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

운영자가 쓰는 화면이다. 밀도가 높고 반복 작업이 많으므로 키보드·일괄 처리·되돌리기를 앞세운다.

| ID | 항목 | 통용 용어 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|---|
| ADM-01 | 콘텐츠 목록·상태 관리 — 초안·발행·보관 | 콘텐츠 목록 (Content List) | 모듈 | 글·상품의 상태별 목록 | 확장 [MK] |
| ADM-02 | 콘텐츠 편집 화면 — 본문·설정 분할 | 콘텐츠 에디터 (Content Editor) | 구성 | 왼쪽 본문, 오른쪽 메타 설정 | 확장 [MK] |
| ADM-03 | 미디어 라이브러리 | 미디어 라이브러리 (Media Library) | 모듈 | 올린 그림·파일 모아 관리 | 확장 [MK] |
| ADM-04 | 메뉴·탐색 구조 편집 | 메뉴 편집기 (Menu Editor) | 모듈 | 사이트 메뉴를 끌어 짜기 | 확장 [MK] |
| ADM-05 | 페이지 빌더 — 블록 조립 | 페이지 빌더 (Page Builder) | 모듈 | 블록을 쌓아 페이지 만들기 | 확장 [MK] |
| ADM-06 | 사용자 관리 — 검색·정지·역할 | 사용자 관리 (User Management) | 모듈 | 회원 찾고 조치하기 | 확장 [MK] |
| ADM-07 | 주문·거래 관리 화면 | 주문 관리 (Order Management) | 모듈 | 주문 상태 바꾸고 환불 | 확장 [MK] |
| ADM-08 | 사이트 설정·일반 설정 | 일반 설정 (General Settings) | 모듈 | 이름·로고·언어 같은 기본값 | 확장 [MK] |
| ADM-09 | 대량 편집·CSV 일괄 갱신 | 일괄 편집 (Bulk Edit) | 구성 | 파일로 한꺼번에 고치기 | 확장 [MK] |
| ADM-10 | 콘텐츠 예약·게시 달력 | 콘텐츠 캘린더 (Content Calendar) | 구성 | 발행 예정을 달력에서 | 확장 [MK] |
| ADM-11 | 번역·다국어 콘텐츠 관리 | 다국어 관리 (Translation Management) | 모듈 | 언어별 본문 상태와 누락 | 확장 [MK] |
| ADM-12 | SEO 메타·미리보기 | SEO 미리보기 (SERP Preview) | 구성 | 검색 결과 모양 미리 보기 | 확장 [MK] |
| ADM-13 | 리다이렉트·URL 관리 | 리다이렉트 관리 (Redirect Manager) | 모듈 | 주소 바꾸고 옛 주소 연결 | 확장 [MK] |
| ADM-14 | 댓글·신고 검토 대기열 — Moderation | 모더레이션 큐 (Moderation Queue) | 모듈 | 올라온 것을 승인·삭제 | 확장 [MK] |
| ADM-15 | 관리자 대시보드 — 오늘 할 일 | 관리자 대시보드 (Admin Dashboard) | 모듈 | 처리 대기 수와 지표 | 확장 [MK] |
| ADM-16 | 감사·변경 이력 보기 | 변경 이력 (Revision History) | 구성 | 누가 무엇을 바꿨는지 | 확장 [MK] · 대조 [GHAUDIT] |
| ADM-17 | 테마·외관 설정 | 테마 설정 (Theme Customizer) | 모듈 | 색·글꼴·레이아웃 고르기 | 확장 [MK] |

| ADM-22 | 도움말 3단계 체계 | 도움말 계층 (Help System Tiers) | 기준 | 짧은 설명·옆 패널·전체 문서 | 확인 [CF] |
