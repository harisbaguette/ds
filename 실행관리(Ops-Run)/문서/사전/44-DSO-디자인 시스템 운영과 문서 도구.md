# 44. 디자인 시스템 운영과 문서 도구

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 44번 분류 DSO다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

디자인 시스템 자체를 보여 주고 관리하는 화면이다. 토큰·부품 문서·놀이터가 있어야 AI와 사람이 같은 기준으로 만든다.

| ID | 항목 | 통용 용어 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|---|
| DSO-01 | 토큰 표 — 색·간격·글자 미리보기 | 토큰 문서 (Design Token Table) | 모듈 | 값과 이름과 실제 모양 나란히 | 확장 [MK] |
| DSO-02 | 부품 문서 페이지 — 예시·속성·코드 | 컴포넌트 문서 (Component Docs Page) | 모듈 | 하나의 부품을 설명하는 표준 틀 | 확장 [MK] |
| DSO-03 | 라이브 놀이터 — 속성 바꿔 보기 | 플레이그라운드 (Playground) | 구성 | 옵션을 바꾸면 바로 바뀌는 예시 | 확장 [MK] |
| DSO-04 | 사용·금지 예시 — Do / Don't | Do·Don't (Do and Don't) | 구성 | 좋은 예와 나쁜 예를 나란히 | 확장 [MK] |
| DSO-05 | 부품 상태 표 — 준비·검토·폐기 | 컴포넌트 상태 (Component Status) | 구성 | 부품별 성숙도 | 확장 [MK] |
| DSO-06 | 변경 기록·마이그레이션 안내 | 변경 로그 (Changelog) | 모듈 | 바뀐 부품과 옮기는 법 | 확장 [MK] |
| DSO-07 | 아이콘 목록·검색·복사 | 아이콘 라이브러리 (Icon Library) | 모듈 | 아이콘 이름 찾아 복사 | 확장 [MK] |
| DSO-08 | 접근성 체크 목록 — 부품별 | 접근성 체크리스트 (Accessibility Checklist) | 구성 | 부품이 지켜야 할 항목 | 확장 [MK] |
| DSO-09 | 코드 예시 — 프레임워크별 탭 | 프레임워크별 코드 탭 (Framework Code Tabs) | 구성 | React·Vue 등 전환 | 확장 [MK] |
| DSO-10 | 디자인·코드 동기화 상태 | 디자인·코드 싱크 (Design-Code Sync) | 구성 | 디자인 파일과 코드 일치 여부 | 확장 [MK] |
| DSO-11 | 글쓰기 가이드 — 문구 규칙 | 보이스 앤 톤 (Voice and Tone) | 모듈 | 말투·용어·대문자 규칙 | 확장 [MK] |
| DSO-12 | 패턴 조합 예시 — 화면 단위 | 패턴 예시 (Pattern Examples) | 모듈 | 부품을 조합한 실제 화면 견본 | 확장 [MK] |
| DSO-13 | 테마 전환 미리보기 — 밝음·어둠·브랜드 | 테마 미리보기 (Theme Preview) | 구성 | 같은 부품의 테마별 모습 | 확장 [MK] |
| DSO-14 | 기여 안내·요청 제출 | 기여 가이드 (Contribution Guide) | 모듈 | 새 부품 제안 절차 | 확장 [MK] |
| DSO-15 | 사용 현황 — 어느 제품이 무엇을 쓰나 | 채택 현황 (Adoption Metrics) | 구성 | 부품 채택 통계 | 확장 [MK] |
| DSO-16 | 시각 회귀 비교 — 전후 스크린샷 | 시각적 회귀 테스트 (Visual Regression Testing) | 구성 | 바뀐 그림 차이 확인 | 확장 [MK] |
| DSO-17 | 동작 시험 패널 — 눌러 보며 검증 | 인터랙션 테스트 (Interaction Tests) | 흐름 | 부품을 실제로 눌러 단계별 확인 | 확인 [STORYINT] |
| DSO-18 | 접근성 자동 검사 결과 탭 — 위반·통과·수동확인 | 접근성 검사 패널 (Accessibility Addon) | 부품 | 부품별 접근성 문제를 탭으로 분류 | 확인 [STA11Y] |
| DSO-19 | 바뀐 부품만 골라 캡처 | 변경분만 스냅샷 (TurboSnap) | 기준 | 변경된 것만 다시 찍어 비용을 줄임 | 확인 [CHTURBO] |
| DSO-20 | 시각 변경 승인·반려 화면 | 시각 변경 리뷰 (Visual Review) | 흐름 | 달라진 그림을 사람이 판정 | 확인 [CHROMREV] |
| DSO-21 | 다른 팀 부품 목록 합쳐 보기 | 스토리북 컴포지션 (Storybook Composition) | 구성 | 여러 저장소의 부품을 한 화면에 | 확인 [STCOMP] |
| DSO-22 | 개발 넘김 준비 상태 표시 | 개발 준비 완료 (Ready for Dev) | 기준 | 어느 화면이 구현 가능한지 표시 | 확인 [FIGDEV] |
| DSO-23 | 디자인 위 주석 — 구현 조건 메모 | 디자인 주석 (Annotations) | 부품 | 그림에 개발용 조건을 적어 둠 | 확인 [FIGDEV] |
| DSO-24 | 변수 모드 전환 — 테마·언어·밀도 | 변수 모드 (Variable Modes) | 부품 | 같은 부품의 값 묶음을 바꿔 봄 | 확인 [FIGVAR] |
| DSO-25 | 디자인-코드 연결 표시 | 코드 커넥트 (Code Connect) | 흐름 | 그림 옆에 실제 코드 조각을 보임 | 확인 [FIGCC] |
| DSO-26 | 부품 속성 정의 — 켜기·교체·글·변형·슬롯 | 컴포넌트 속성 (Component Properties) | 구성 | 부품이 받을 수 있는 설정의 종류 | 확인 [FIGPROP] |
| DSO-27 | 토큰 변환 파이프라인 | 토큰 변환 파이프라인 (Style Dictionary) | 흐름 | 값 하나를 여러 플랫폼 코드로 | 확인 [SDICT] |
