# 52. TV·키오스크·차량·손목 화면

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 52번 분류 DVC다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

손가락과 마우스가 아닌 방식으로 조작하거나, 멀리서 보거나, 아주 작은 화면의 항목이다.
