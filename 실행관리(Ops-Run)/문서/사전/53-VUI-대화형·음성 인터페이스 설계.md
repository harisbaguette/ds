# 53. 대화형·음성 인터페이스 설계

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 53번 분류 VUI다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

글자 입력창이 아니라 말과 대화 흐름으로 일을 끝내는 항목이다. AI 채팅(24번)과 겹치는 부분은 그쪽에 두고, 대화 설계 규칙만 여기 둔다.

| ID | 항목 | 종류 | 역할·사용할 때 | 근거 |
|---|---|---|---|---|
| VUI-01 | 대화 시작 — 무엇을 할 수 있는지 | 구성 | 첫 말에 가능한 일 알려 주기 | 확장 [MK] |
| VUI-02 | 의도 확인·되묻기 | 구성 | 애매하면 짧게 확인 | 확장 [MK] |
| VUI-03 | 빈칸 채우기 대화 — 필요한 값 순서대로 묻기 | 흐름 | 날짜·인원 차례로 받기 | 확장 [MK] |
| VUI-04 | 오류 복구 — 못 알아들었을 때 | 구성 | 다시 말하기·다른 방법 제시 | 확장 [MK] |
| VUI-05 | 대화 안 선택지 버튼 — Quick Replies | 부품 | 말 대신 누를 답 | 확장 [MK] |
| VUI-06 | 사람에게 넘기기 시점 | 기준 | 봇이 포기할 조건 | 확장 [MK] |
| VUI-07 | 대화 기록·이어 하기 | 구성 | 전 대화 이어서 | 확장 [MK] |
| VUI-08 | 확인 요약 후 실행 | 구성 | 실행 전 정리해서 보여 주기 | 확장 [MK] |
| VUI-09 | 음성 대기·듣는 중 표시 | 부품 | 지금 듣고 있음을 표시 | 확장 [MK] |
| VUI-10 | 말 끊기·중단 허용 | 기준 | 답하는 중에도 끼어들기 | 확장 [MK] |
| VUI-11 | 짧은 답과 자세한 답 — 요청 시 확장 | 기준 | 먼저 짧게, 원하면 길게 | 확장 [MK] |
| VUI-12 | 페르소나·말투 일관성 | 기준 | 봇의 성격 유지 | 확장 [MK] |
| VUI-13 | 민감 요청 처리 — 거절과 안내 | 구성 | 못 하는 이유와 대안 | 확장 [MK] |
| VUI-14 | 다국어 감지·전환 | 구성 | 말한 언어로 답하기 | 확장 [MK] |
| VUI-15 | 대화 만족도·문제 신고 | 구성 | 답이 도움이 됐는지 표시 | 확장 [MK] |
| VUI-16 | 응답값 검증 되묻기 | 부품 | 값이 규칙에 안 맞으면 다시 물음 | 확인 [ALEXADLG] |
| VUI-17 | 대화 자동 위임 | 흐름 | 빠진 정보를 시스템이 채워 물음 | 확인 [ALEXADLG] |
| VUI-18 | 되물음 세기 구분 — 암시적·명시적 | 기준 | 위험한 일만 또박또박 확인 | 확인 [GCDCONF] |
| VUI-19 | 말 끝났는지 판단 — 무음 기준·의미 기준 | 기준 | 언제 대답을 시작할지 | 확인 [OAIVAD] |
| VUI-20 | 말 끊을 때 응답 중단 | 흐름 | 사용자가 말하면 즉시 멈춤 | 확인 [OAIVAD] |
