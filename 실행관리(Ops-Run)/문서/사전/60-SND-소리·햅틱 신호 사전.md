# 60. 소리·햅틱 신호 사전

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 60번 분류 SND다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

화면 밖으로 전하는 소리와 진동의 사건 이름 목록이다. 소리는 늘 시각 표시와 함께 쓰고 사용자가 꺼 둔 설정을 먼저 따른다.

|---|---|---|---|---|---|
| SND-01 | 소리 — 탭 틱 | 탭 사운드 (Tap Feedback) | 기준 | 눌렸음을 알리는 아주 짧은 소리·진동 | 확장 [MK] |
| SND-02 | 소리 — 토글 켜짐 | 토글 켜짐음 (Toggle On Sound) | 기준 | 스위치를 켤 때 나는 신호 | 확장 [MK] |
| SND-03 | 소리 — 토글 꺼짐 | 토글 꺼짐음 (Toggle Off Sound) | 기준 | 스위치를 끌 때 나는 신호 | 확장 [MK] |
| SND-04 | 소리 — 선택 변경 | 선택 틱 (Selection Tick) | 기준 | 눈금·바퀴를 지나며 고른 값이 바뀔 때 나는 신호 | 확장 [MK] |
| SND-05 | 소리 — 성공 | 성공음 (Success Sound) | 기준 | 일이 잘 끝났을 때 나는 신호 | 확장 [MK] |
| SND-06 | 소리 — 경고 | 경고음 (Warning Sound) | 기준 | 그대로 두면 문제가 될 때 나는 신호 | 확장 [MK] |
| SND-07 | 소리 — 오류 | 오류음 (Error Sound) | 기준 | 실패해서 손봐야 할 때 나는 신호 | 확장 [MK] |
| SND-08 | 소리 — 알림 도착 | 알림음 (Notification Sound) | 기준 | 새 알림이 왔을 때 나는 신호 | 확장 [MK] |
| SND-09 | 소리 — 메시지 보냄 | 발신음 (Message Sent Sound) | 기준 | 보내기가 끝났을 때 나는 신호 | 확장 [MK] |
| SND-10 | 소리 — 메시지 받음 | 수신음 (Message Received Sound) | 기준 | 새 메시지가 들어왔을 때 나는 신호 | 확장 [MK] |
| SND-11 | 소리 — 삭제 | 삭제음 (Delete Sound) | 기준 | 무언가를 지웠을 때 나는 신호 | 확장 [MK] |
| SND-12 | 소리 — 되돌리기 | 실행 취소음 (Undo Sound) | 기준 | 방금 한 일을 취소했을 때 나는 신호 | 확장 [MK] |
| SND-13 | 소리 — 완료 팡파르 | 축하 효과음 (Celebration Sound) | 기준 | 긴 과정을 끝냈을 때만 쓰는 축하 신호 | 확장 [MK] |
| SND-14 | 소리 — 카운트다운 | 카운트다운 사운드 (Countdown Tick) | 기준 | 남은 시간이 줄어드는 동안 반복되는 신호 | 확장 [MK] |
| SND-15 | 소리 — 타이머 끝 | 타이머 알람 (Timer Alarm) | 기준 | 정해 둔 시간이 다 됐을 때 나는 신호 | 확장 [MK] |
| SND-16 | 소리 — 스크롤 끝 반동 | 오버스크롤 피드백 (Overscroll Bounce) | 기준 | 더 갈 곳이 없어 튕길 때 나는 신호 | 확장 [MK] |

| SND-19 | 소리 — 놓기 | 드롭 피드백 (Drop) | 기준 | 끌던 것을 제자리에 떨어뜨렸을 때 나는 신호 | 확장 [MK] |
| SND-20 | 소리 — 잠금 | 잠금음 (Lock Sound) | 기준 | 화면이나 기능을 잠갔을 때 나는 신호 | 확장 [MK] |
| SND-21 | 소리 — 잠금 해제 | 잠금 해제음 (Unlock Sound) | 기준 | 잠금이 풀렸을 때 나는 신호 | 확장 [MK] |
| SND-22 | 소리 — 결제 완료 | 결제 완료음 (Payment Success Sound) | 기준 | 값이 치러졌음을 확실히 알리는 신호 | 확장 [MK] |
| SND-23 | 소리 — 카메라 셔터 | 셔터음 (Camera Shutter) | 기준 | 사진이 찍혔음을 알리는 신호 | 확장 [MK] |
| SND-24 | 소리 — 녹음 시작 | 녹음 시작음 (Record Start) | 기준 | 녹음이 켜졌음을 알리는 신호 | 확장 [MK] |

| SND-26 | 소리 — 호출음 | 벨소리 (Ringtone) | 기준 | 전화나 영상 통화가 걸려올 때 이어지는 신호 | 확장 [MK] |

| SND-30 | 소리 — 전송 실패 | 전송 실패음 (Send Failed Sound) | 기준 | 보내기가 안 됐을 때 나는 신호 | 확장 [MK] |

| SND-32 | 소리 — 페이지 넘김 | 페이지 넘김음 (Page Turn Sound) | 기준 | 책·슬라이드를 넘겼을 때 나는 신호 | 확장 [MK] |
| SND-33 | 소리 — 화면 읽기 안내음 | 스크린 리더 이어콘 (Earcon) | 기준 | 보조기술이 초점 이동과 경계를 알릴 때 쓰는 신호 | 확장 [MK] |
