# 74. 게임 접근성

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 74번 분류 GAC다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

이 분류는 장애나 일시적인 불편이 있는 사람도 모바일·PC·콘솔 게임을 끝까지 즐길 수 있게 하는 게임 전용 옵션, 표시, 규칙을 모은다. 대비·초점·랜드마크처럼 게임이 아닌 화면에도 똑같이 쓰는 일반 접근성 기준은 ACS·ARI에 두고, 버튼 재배치·누름 전환·화면 흔들림 세기·안전영역은 GAM-21~24를 따른다. 판단이 갈리면 "장애나 불편을 줄이는 게임 옵션인가"를 기준으로 이 분류에 넣는다.
