# 75. 국내 전용 화면·인증·결제·연동

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 75번 분류 KOR이다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

한국에서만 쓰는 화면 관례를 모은다. 휴대폰 본인확인·인증서·국내 결제 수단·현금영수증·카카오와 네이버 연동·공공 누리집 부품·국내 법이 요구하는 표시·한글 처리처럼, 한국의 제도와 서비스 생태계 때문에 생긴 판단만 담는다. 로그인·결제·동의·보안·접근성의 일반 원칙과 이미 다른 분류에 있는 항목(SEC-24~26, FLW-22, BIL-26, PRV-25~26, DOM-75, INP-81~82, FMT-22·38, COM-37)은 담지 않는다.
