# 76. 콘텐츠 뷰어·미디어 소비

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 76번 분류 CNT다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

읽고 보고 듣는 소비 화면을 모은다. 전자책·웹툰 뷰어, 팟캐스트·오디오북, 뉴스와 긴 글, RSS·뉴스레터 리더, 사진 보관함, 영상 OTT, 라이브 방송 시청, 숏폼, 음악, 문서 뷰어에서 콘텐츠를 보는 동안 필요한 판단만 담고, 모바일과 PC 화면을 함께 다룬다. 플레이어 기본 조작·통화·회의(MED-01~36), 저장·스토리·라이브 참여·팁·민감 가리기(SOC-06·16·17·26·27), 갤러리·읽기 설정·하이라이트·읽기 시간·스포일러·연재 알림(EDT-14·19·25·27·37·41), 오프라인 보관 일반(MOB-14), 사진 자동 분류(DOM-52), PDF 주석 편집(FIL-13)은 담지 않는다.
