# 82. 매거진·뉴스·기사 화면

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 82번 분류 MAG이다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

이 분류는 웹 기사, 모바일 기사, 인쇄 지면에서 기사를 짜고 믿을 수 있게 보여 주는 방법을 담는다. 기사 머리의 제목·바이라인·날짜, 신뢰 라벨과 정정, 긴 기사의 스크롤 연출, 잡지의 호 구성, 뉴스 첫 화면, 유료 벽의 종류, 광고 표시, 신문 지면의 판형과 격자가 여기에 속한다. 읽기 모드·목차·진행 막대·페이월 기본형·속보 띠·오디오 기사(CNT-51~61, CNT-65), 캡션 열·사진 시퀀스·잡지형 지면(ART-08·09·11·24), 러닝 헤더·드롭캡·다단(TYP-11·12·13·18·20·27), 양면 인쇄(DOC-09), 아카이브·관련 글·수정 이력·라이브 업데이트·요약 박스·작성자 소개(EDT-05·06·08·20·23·36·38·47·48·49·50), 뉴스레터 구독과 스크롤텔링(WEB-14·42)은 이미 다른 분류에 있어 넣지 않는다.
