# 84. 발표·슬라이드·인포그래픽·카드뉴스

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 84번 분류 SLD다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

발표 슬라이드, 인포그래픽, 카드뉴스처럼 한 장씩 넘기며 메시지를 전하는 자료의 판 종류와 제작·진행·배포 규칙을 모은다. 파워포인트·키노트·구글 슬라이드·피그마 슬라이드의 발표 기능과 인스타그램·링크드인 게시 규격도 여기에 둔다. 발표 편집기 화면(PRO), 차트 종류(CHR), 발표 템플릿과 소셜 자산(AST), 문서 발표 보기(DOC)에 이미 있는 항목은 다시 싣지 않는다.
