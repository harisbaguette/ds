# 85. 인쇄·브랜드 가이드·패키지·안내판

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 85번 분류 PRT다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

이 분류는 종이·포장·공간에 실제로 찍히거나 세워지는 결과물을 만들 때 필요한 규칙과 부품을 다룬다. 브랜드 가이드의 사용 규칙, 인쇄 파일 준비와 후가공, 인쇄물 종류, 포장 표시, 길찾기 안내판과 공간 그래픽, 굿즈가 여기에 속한다. 명함·포스터·현수막·로고 파일 같은 자산 규격은 64-AST에서, 화면으로 보여 주는 디지털 사이니지는 52-DVC에서 다루므로 여기서는 제외한다.
