# 87. 금융·자산 화면

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 87번 분류 FIN이다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

돈과 자산이 실제로 움직이는 화면을 모은다. 은행 계좌와 송금, 카드, 증권 투자, 보험, 대출, 자산 관리, 지갑·핀테크, 그리고 금융 규제가 요구하는 신뢰 표현까지 국내와 해외 관례를 함께 담는다. 결제 입력·영수증·구독 일반(BIL), 국내 본인확인·인증서·간편결제(KOR), 일반 보안 경험(SEC)과 이미 있는 항목(SEC-14·17 마스킹과 보안 키패드, FMT-37 번호 마스킹, FMT-45 다중 통화, KOR-47 1원 인증, KOR-48 은행 고르기, KOR-61 무이자 할부 표, KOR-109 만 단위 입력, BIL-30 3DS, CHR-22 캔들 차트)은 담지 않는다.
