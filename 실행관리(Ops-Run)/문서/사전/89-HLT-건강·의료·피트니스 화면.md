# 89. 건강·의료·피트니스 화면

[패턴 사전 색인과 사용법](<../패턴 사전 색인과 사용법.md>)의 89번 분류 HLT다. 항목 ID·종류·근거 표기 규칙은 색인 문서의 "목록을 읽는 기준"을 따르고, 근거 칸의 출처 기호는 [레퍼런스 출처 대장](<../레퍼런스 출처 대장.md>)의 "출처 기호표"에서 원문으로 이어진다.

몸과 마음의 건강을 다루는 화면 요소를 모은다. 진료 접수와 비대면 진료, 검사 결과, 복약, 운동 기록, 건강 지표, 마음 건강, 웨어러블 연동 권한, 민감한 건강 정보의 표현과 쉬운 말 기준을 담는다. 일반 예약 달력(SCH), 차트 형식(CHR), 손목 화면(DVC), 고령 모드와 위기 상담 카드(AGE), 의료기기 알람과 환자 확인 화면(IND), 일반 권한·익명 모드·잠금 화면 표시(MOB·PRV·MSG)는 각 분류에서 다룬다.
