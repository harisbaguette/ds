# 패토브 디자인 브리프

2026-09-24. 최신 지시: 내부는 나중에 채운다. 사이트 외부는 스타일을 중심으로 lean하게 뺀다.
사용자 발언이 이전 시안·기능 목록보다 우선한다.

## 문제와 목적

주 사용자는 원하는 결과물을 만들기 위해 일관된 스타일의 부품을 찾는 사람이다.
프로젝트 정의에 근거한 작업 가정이며 별도 사용자 조사를 했다는 뜻은 아니다.
최종 목표는 같은 스타일의 부품을 AI가 찾아 조합해 사람이 보정하지 않아도 되는 결과물이다.

이 사이트의 첫 과제는 스타일을 눈으로 고르는 것이다.
두 번째는 그 스타일 안에서 필요한 것을 찾는 것이다.
많은 도구를 동시에 보여 주는 것은 완성도의 증거가 아니다.

## 사용자 피드백으로 확정된 기준

- 패턴끼리 비교는 불필요하다. 스타일의 차이가 중요하다.
- 그리드는 유지한다. 리스트 모드는 제거한다.
- 제목을 크게 만들 필요가 없다.
- 로고 텍스트가 필요 없다.
- 내부 스타일과 상세 내용보다 외부 뼈대를 먼저 정한다.
- 목표에 기여하지 않는 기능·장식은 추가하지 않고 뺀다.

이 지시를 ‘로고 글자만 지우고 나머지는 그대로 유지’하는 국소 수정으로 해석하지 않는다.
첫 화면·탐색 순서·기능 위계까지 함께 바꾼다.

## 수용 기준

| 상황 | 행동 | 결과 |
|---|---|---|
| 처음 방문 | 화면 확인 | 스타일 표지 세 개가 중심, 큰 제목·도구막대 없음 |
| 스타일 결정 | 표지 선택 | 그 스타일의 패턴 그리드가 열림 |
| 필요한 패턴 찾기 | 검색·분류 | 실제 일치 항목만 표시 |
| 찾는 중 스타일 변경 | 상단 스타일 선택 | 검색·분류 유지, 목록 전체 스타일 변경 |
| 상세 확인 | 항목 선택·닫기 | 현재 스타일로 열리고 원래 항목에 초점 복귀 |
| 다시 찾을 항목 | 저장 | 스타일별 보관, 해제·되돌리기 가능 |
| 작은 화면·키보드 사용 | 같은 흐름 실행 | 중복 메뉴 없이 탐색, 44px 조작·초점 유지 |

## 시안과 검수

이미지 시안 두 장으로 스타일 입구와 패턴 그리드의 구도를 검토했다.
생성 이미지의 임의 로고·추가 내부 장식·카드 외곽선은 제외했다.
기존 로고와 내부 표본을 재사용해 외부 구현을 만든 뒤 실제 화면에서 다시 검수했다.
