# 스타일을 먼저 고르는 패토브

2026-09-24. 최신 사용자 지시: 비교·리스트·큰 제목·로고 글자는 필요 없다.
한 스타일로 일관되게 가져다 쓰는 목표에 맞춰 사이트 외부를 lean하게 줄인다.

## 스스로 비판한 점

이전에는 기능을 늘리는 일을 완성도 개선으로 착각했다.
비교·정렬·보기 전환·중복 메뉴를 동시에 꺼내 놓아 스타일보다 조작 도구가 먼저 보였다.
정의 문서의 ‘같은 스타일의 부품을 가져와 조합한다’는 목표를 탐색 구조에 반영하지 못했다.

작은 요소만 지우는 대신 첫 진입부터 바꿨다. 현재 흐름은 **스타일 → 그 스타일의 그리드 → 상세**다.
검색·분류는 필요한 것을 찾는 도구로 남겼다. 저장은 보조 동작으로 낮추고 스타일별로 묶었다.

시안 두 장은 built-in image_gen으로 만들었다. [정확한 생성 프롬프트와 제외 판단](../시안/2026-09-24/스타일-우선/생성-프롬프트.md)을 함께 보관한다.
생성 이미지는 구도 검토용이다. 내부 예시의 최종 디자인이나 기능 구현 증거로 사용하지 않는다.

## 목표에 따라 제거한 것

- 패턴 간 비교: 선택 모드·카드 체크박스·도크·비교 창·상세 비교 버튼까지 제거.
- 리스트 보기와 보기 전환, 정렬, 큰 페이지 제목·개수 배지 제거.
- 로고 워드마크·주 메뉴 중복·접는 사이드바·모바일 하단 메뉴·분류 서랍 제거.
- 상세마다 스타일을 바꾸는 조작과 스타일 표지의 장면 전환 제거.

시작 화면에는 세 스타일의 표지만 둔다. 그리드의 스타일 변경은 상단 한곳에서 한다.
데스크톱의 카드 저장은 호버·키보드 초점·저장된 상태에서만 드러난다. 모바일·터치에서는 항상 보인다.

## 검증과 경계

- `npm test`: 기능 41개 통과. 스타일 전환·검색·상세·저장·뒤로/앞으로·저장소 오류 포함.
- `npm run test:outer`: 89개 통과. 320·375·768·1101·1440·1920px, 불필요 조작 제거·메뉴 경계·초점·상세 확인.
- `npm run test:visual`: 30개 화면 조합, 실패 0. 사라진 기능을 검사에서 제거하고 스타일 표지·그리드를 검증.
- `npm run test:design`: 16개 주소/화면 조합, 검사 대상의 조작 크기·이름·텍스트 대비·가로 넘침 문제 0.
- `design_lint.py`: ERROR 0 / WARN 60. 작은 보조 라벨·비조작 표본·기존 모서리 값·theme-color 경고는 실제 화면에서 구별해 확인.
- 로컬 HTTP 응답 200. 파일 실행과 HTTP 실행 검증. Chrome 검수이며 접근성 전체 인증·실기기 사용자 실험은 아니다.

내부 `previews.js`, `previews.css`, `catalog.js`의 SHA256은 이번 작업 전과 같다.
외부 표지 래퍼에서 기존 스타일 장면의 하단 할 일 영역만 제외했다. 기존 원본을 다시 디자인하지 않았다.
현재 12개 예시와 상세 빈 자리는 뼈대 검토용이다. 전체 사전의 목표·부품 배포 목표는 축소하지 않았다.
이 기록은 자체 검수다. 사용자 승인을 받았다고 쓰지 않는다.
