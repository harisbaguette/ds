# 갈피 / galpi 브랜드 설계

> 이전 갈피 시안의 기록. 현재안은 [패토브 재설계](../패토브-재설계/README.md)이며, 아래 결정을 현재 제품 기준으로 사용하지 않는다.

이 문서는 최종 시안의 설계 기준이다. 색·서체·치수는 구현 목표이며 생성 PNG에 정확한 수치로 적용되었다는 뜻은 아니다. 실제 사용한 프롬프트는 [생성 프롬프트](생성-프롬프트.md)에 있다.

## 방향 결정

이 브랜드의 이름은 **갈피 / galpi**로 잡는다. 사전, 책갈피, 찾는 자리, 다시 돌아갈 위치가 한 단어에 들어 있고, 이 프로젝트가 하려는 일인 "패턴을 눈으로 찾고 바로 이해하는 일"과 맞는다. 상표 고유성은 검증하지 않았다.

제품 형태는 기존 확정 구조를 유지한다. KAWAI식 실제 웹 사전처럼 **검색, 좌측 분류, 3열 미니어처 갤러리, 중앙 상세 모달**이 중심이다. shadcn처럼 외곽은 조용한 흰색, 회색 선, 정상적인 웹 밀도에 둔다. 브랜드의 개성은 파란 네모 로고나 색상 교체가 아니라, 작은 기호, 미니어처의 선과 색면, 표면 깊이, 여백의 리듬에서 나온다.

## 로고

기호 이름은 **갈피표**다. 24px에서는 작은 사전 카드의 오른쪽 위가 접힌 모양과, 안쪽에 끼워진 책갈피 탭을 한 번에 보이게 한다. 16px에서는 외곽선을 줄이고, 접힌 모서리와 탭만 남겨도 알아볼 수 있어야 한다.

- 24px: 약 18×22px의 세로 카드에 작은 모서리. 오른쪽 위는 접힌 삼각형, 왼쪽 안쪽에는 세로 책갈피 탭 1개. 선 두께 1.75px.
- 16px: 약 12×15px의 세로 카드 실루엣. 접힌 모서리 1개와 안쪽 짧은 탭만 남긴다. 작은 크기에서는 글자 `ㄱ`를 억지로 넣지 않는다.
- 색상: 기본은 먹색 선과 갈피청록 탭. 선택 상태에서는 탭 면만 갈피청록으로 채우고 접힌 모서리는 종이색으로 남긴다.
- 워드마크: 한국어 `갈피`는 단단한 고딕 기반의 직접 조정 글자, 라틴 `galpi`는 한글과 무게를 맞춘 소문자 워드마크. 앱 헤더에서는 `갈피`만 쓰고, 브랜드 키트에서 `galpi` 병기를 보여준다.

## 시각 시스템

### 색

| 역할 | 이름 | 값 | 쓰임 |
|---|---|---:|---|
| 배경 | 종이 | `#F7F8F4` | 페이지 전체의 따뜻한 흰색 |
| 표면 | 카드 | `#FFFFFF` | 카드, 모달, 검색창 |
| 선 | 먹선 옅음 | `#D9DED8` | 카드 경계, 분리선 |
| 본문 | 먹색 | `#20272B` | 제목, 본문, 아이콘 |
| 보조 본문 | 회먹색 | `#536168` | 설명, 도움말 |
| 브랜드 | 갈피청록 | `#176E7A` | 선택, 초점, 주요 활성 |
| 보조 강조 | 색인노랑 | `#F2D45C` | 미니어처 안의 작은 주의점, 책갈피 탭 |
| 차분한 면 | 하늘종이 | `#E6F4F5` | 빈 상태, 로딩, 작은 도해 배경 |

파랑을 완전히 금지하지는 않지만, 기존 시안의 일반적인 파란 선택색은 갈피청록으로 바꾼다. 성공, 경고, 오류는 의미색으로만 쓰고 브랜드 색을 덮지 않는다.

### 서체

UI 기본은 **SUIT Variable** 계열을 우선한다. 없을 때는 `system-ui`, `Apple SD Gothic Neo`, `Noto Sans KR` 순서로 대체한다. 라틴 워드마크는 별도 글자 조정으로 만들고, 본문용 라틴은 UI 서체와 같은 패밀리 안에서 처리한다. Inter/Roboto를 브랜드의 표정으로 쓰지 않는다.

- 카드 제목: 15-16px, 650.
- 한 줄 용도: 13-14px, 400, 줄높이 1.45.
- 분류와 태그: 12-13px, 500. 전부 대문자 라벨을 쓰지 않는다.
- 큰 상세 제목: 20-22px, 700. 대형 포스터 제목은 만들지 않는다.

### 공간과 표면

8px 기반으로 잡되, KAWAI처럼 카드 안의 미니어처가 먼저 보이게 한다.

- 1440px 기준 헤더 64-72px, 좌측 분류 약 240px.
- 카드 3열, 16px 거터, 카드 모서리 8px.
- 카드 미니어처 영역은 카드 높이의 62-66%, 정보 영역은 34-38%.
- 카드와 모달은 선을 먼저 쓰고 그림자는 보조로만 쓴다.

그림자는 `beautiful-shadows`의 중립 레이어 원칙을 따른다.

- 작은 카드/검색창: `0px 2px 3px -1px rgba(0,0,0,0.10), 0px 1px 0px 0px rgba(25,28,33,0.02), 0px 0px 0px 1px rgba(25,28,33,0.08)`
- 팝오버/떠 있는 패널: `0px 0px 0px 1px rgba(0,0,0,0.06), 0px 1px 1px -0.5px rgba(0,0,0,0.06), 0px 3px 3px -1.5px rgba(0,0,0,0.06), 0px 6px 6px -3px rgba(0,0,0,0.06), 0px 12px 12px -6px rgba(0,0,0,0.06), 0px 24px 24px -12px rgba(0,0,0,0.06)`
- 강한 그림자는 상세 모달에만 제한한다. 색 그림자와 흐릿한 글로우는 쓰지 않는다.

### 미니어처와 일러스트

영감보관함의 선, 평평한 색면, 큰 여백은 전체 껍데기가 아니라 **미니어처 실물**에 들어간다. Karita 명함의 검은 선, 우유병 포스터의 큰 단색면, MYTURN의 격자와 완료 상태, 위생 도해의 행동 장면을 섞되 모든 카드에 캐릭터를 붙이지 않는다.

- 기본 미니어처: 먹색 1.5px 선, 회색 면, 갈피청록 활성.
- 상태 미니어처: 성공/경고/오류는 의미색과 아이콘을 함께 쓴다.
- 빈 상태와 온보딩: 작은 선화 도해를 허용한다.
- 설명 도해: 장면은 "상태 이해"에 필요할 때만 넣고, 장식 풍경은 금지한다.

### 동작

목록의 모든 미니어처가 동시에 움직이면 사전 탐색을 방해한다. 기본은 정적 프레임이고, hover, focus, selected, 상세 모달에서만 짧게 작동한다.

- 카드 hover/focus: 160ms, 경계가 갈피청록으로 바뀌고 해당 미니어처만 짧게 재생된다.
- 카드 press: pointer-down에 즉시 표면 피드백. 큰 카드 전체의 확대·축소는 생략한다.
- 상세 모달: 최대 280ms, 데스크톱 중앙·모바일 아래쪽을 기준으로 전환. dim은 배경 목록 구조가 남을 정도.
- 검색/분류 전환: 180ms opacity. 반복 검색에서 목록 전체의 위치 이동은 생략한다.
- reduced motion: 이동과 탄성을 제거하고 opacity/color 변화로 대체한다.

### 접근성과 모바일

브랜드 기호와 아이콘 버튼에는 보이는 툴팁보다 먼저 접근 가능한 이름이 있어야 한다. 선택은 색만으로 표시하지 않고, 왼쪽 막대, 배경, 아이콘 상태를 함께 쓴다. 포커스 링은 갈피청록 2px와 2px offset을 기본으로 한다.

모바일에서는 좌측 분류를 상단 분류 선택으로 접고, 3열 갤러리는 1열 카드 목록으로 바꾼다. 패턴·스타일·영감은 하단 탐색에 유지한다. 상세는 중앙 모달이 아니라 하단 시트로 열린다. 미니어처는 카드 위쪽에 크게 남기고, 코드나 파일 선택은 넣지 않는다.

## 반려 기준

- 파란 네모 아이콘만 남고 이름과 기호의 이유가 보이지 않으면 실패.
- KAWAI식 웹 사전 구조가 사라지고 표본판, 포스터, 랜딩 히어로가 되면 실패.
- 미니어처보다 코드 복사, 파일 다운로드, 설치 버튼이 더 커지면 실패.
- 영감보관함 표현이 모든 카드의 장식 캐릭터로 번지면 실패.
- 그림자를 색 글로우나 무거운 카드 그림자로 처리하면 실패.
- 브랜드 색만 바꾸고 기존 UI 밀도, 서체, 로고, 여백이 그대로면 실패.
