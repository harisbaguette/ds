# 디자인 패턴 사전과 부품 라이브러리

현재 검토할 결과: [패토브 브랜드와 클릭 가능한 사전 시안](패토브-재설계/README.md). 이름·분류·상황 검색·비교·스타일·모바일을 재설계하고 실제 브라우저에서 확인했다. 아래는 이전 시안의 기록이다.

> **미채택 시안.** 아래 3장은 소스를 가져오는 AI의 작업을 사람이 조작하는 코드·파일 화면으로 잘못 옮겼다. 사용자가 요구한 영감보관함 기반의 시각 사전 방향을 충족하지 못했으므로 최종안으로 사용하지 않는다. 재검토 근거는 [재검토 기록](재검토/레퍼런스-대조.md)에 남긴다.

만들 대상은 디자인 패턴 사전, 스타일별 디자인 시스템, shadcn처럼 필요한 코드를 가져와 조합하는 부품 묶음이다. 아이콘·세부 표현·컴포넌트·모듈을 개별로 가져오며 React·Next.js와 일반 HTML의 구현을 같은 항목에서 찾을 수 있어야 한다.

이번 이미지들은 제품 구조와 표현을 비교하는 정적 시안이다. 이미지 속 코드·파일 크기·세부 항목 라벨은 예시이며 실제 배포물이나 동작 검증 결과가 아니다. 스타일 이름도 방향 검토를 위한 가칭이다.

## 읽은 범위

작업 시작 시점의 원본 Markdown 문서 74개, 총 6,961줄을 메인과 범위별 담당자가 본문 끝까지 읽었다. 사전 66개를 모두 포함한다. 참고 이미지 49장은 시각 담당자가 실제 이미지로 모두 확인했다. 숨겨진 작업 사본에서는 원본과 동일한 문서 72개 및 정의 문서의 추가 문단을 대조했다.

문서 및 이미지의 전체 경로·줄 수·SHA-256은 [검토 대상 기록](검토-대상.json)에 있다. 외부 URL을 새로 전수 조사한 작업은 아니다. 기존 원본 문서는 변경하지 않았다.

생성 도구는 내장 `image_gen`이며, 사용한 [생성 프롬프트](생성-프롬프트.md)를 함께 보관한다. 이전 루틴 앱 방향은 만들 대상을 잘못 잡은 결과로 미채택했으며, 그 기록은 `이전-앱예시/`에 분리했다.
