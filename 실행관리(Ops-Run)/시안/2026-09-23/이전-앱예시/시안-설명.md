# 스타일별 디자인 시스템 시안

이 프로젝트는 패턴 사전을 바탕으로 스타일별 토큰·아이콘·세부 표현·컴포넌트·모듈을 만들고, 필요한 단위의 소스를 가져와 조합하는 디자인 시스템을 목표로 한다. Next.js·React와 일반 HTML에서 같은 디자인 자산과 기준을 재사용해야 한다.

이번 산출물은 그 시스템이 만들어 낼 화면과 부품의 **시각 방향을 비교하는 정적 시안 4장**이다. '하루 루틴'은 스타일 비교를 위한 가상의 적용 사례이며, 프로젝트를 루틴 앱으로 한정하는 결정이 아니다. 코드·상호작용·접근성·React와 HTML의 동등성은 이번 이미지 생성으로 검증되지 않는다.

## 전체 자료 확인

작업 시작 시점의 원본 Markdown 문서 **74개, 6,961줄**을 담당 범위로 나눠 본문 끝까지 읽었다. 참고 이미지 **49장**도 실제 이미지로 확인했다. 문서 및 이미지별 경로와 SHA-256은 [검토 대상 기록](../검토-대상.json)에 있다.

사전 본문의 실제 항목 행은 3,917개다. 루트 README의 3,915개 표기와 차이가 있다. 이번 작업에서는 원본 문서를 수정하지 않았다. 외부 URL의 내용을 새로 전수 조사한 작업은 아니며, 저장소 안에 제공된 문서 전체를 읽은 작업이다.

## 비교 기준

네 안 모두 '물 마시기(완료)·책 읽기 25분(선택)·산책 10분·책상 정리 5분'을 예시 콘텐츠로 사용한다. 진행은 1/4, 선택된 타이머는 25:00, 주행동은 '집중 시작'으로 맞춘다.

| 시안 | 시각 방향 | 주요 차이 |
|---|---|---|
| 01 선명한 표지판 | 단색 포스터·큰 픽토그램 | 굵은 선, 강한 색면, 큰 조작부 |
| 02 하늘빛 편집 | 풍경·포스터의 편집 구성 | 가로 흐름, 이미지 크롭, 조판 위계 |
| 03 다정한 선화 | 행동을 직접 보여 주는 그림 | 정돈된 손그림, 루틴 격자, 친근한 부품 |
| 04 고요한 색면 | 차분한 생산성 화면 | 시간대별 띠, 낮은 장식 밀도, 절제된 선 |

그림은 행동과 상태를 설명하고, 이름·시간·행동 라벨은 짧고 명확하게 유지한다. 모바일은 데스크톱을 축소하지 않고 정보 위계를 조정한다. 화면에 쓰인 버튼·입력·아이콘·상태 표현을 별도 표본으로 보여 준다.

생성 방식: 내장 `image_gen`. 실제 사용한 프롬프트는 [생성 프롬프트](생성-프롬프트.md)에 저장한다.
