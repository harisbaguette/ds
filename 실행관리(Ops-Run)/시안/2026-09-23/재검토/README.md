# 영감보관함 기반 시각 사전 시안

> **이전 표본판 시안.** 이후 사용자가 지정한 KAWAI 웹 사전의 검색·분류·미니어처 목록·상세 모달 구조를 충분히 반영하지 못했다. 현재 검토할 화면은 [패토브 브랜드와 클릭 가능한 사전 시안](../패토브-재설계/README.md)이다.

영감보관함의 표현을 실제 부품·상태에 옮겨, 사전 항목을 눈으로 비교하는 정적 시안 세 장이다. 필요한 소스를 AI가 가져오는 전제로, 사람에게 코드 복사나 파일 선택을 시키는 화면은 담지 않았다.

| 이전 이미지 | 영감 원본에서 가져온 특징 |
|---|---|
| [선과 격자](01-선과-격자-v2.png) | MYTURN의 연결된 격자, Karita의 간단한 검은 선과 여백 |
| [단색과 실루엣](02-단색과-실루엣-v2.png) | 우유병·Sushi의 큰 단색면과 반전 대비, 노랑 버튼의 눌림 깊이 |
| [색면과 장면](03-색면과-장면-v2.png) | 바다 홈의 평평한 색면, 두 화분의 상태 비교, 설명도해의 동작 표현 |

버튼·탭·체크박스·진행·로딩·빈 상태 여섯 항목의 순서를 맞췄다. 마지막 안은 같은 항목에 사용 장면과 상태 도해를 추가했다. 이 여섯 항목은 전체 사전에서 표현을 비교하기 위해 고른 표본이다. 전체 사전 완성본이나 작동하는 컴포넌트는 아니다.

세 이미지 모두 1672×941 PNG이며 내장 `image_gen`으로 제작했다. `-v2` 없는 이미지는 검수 전 초안으로 보관한다. 초기 생성에서는 실제 KAWAI 화면을 편집 대상으로, 영감 원본을 스타일 참조로 입력했다. 수정에서는 각 초안과 필요한 영감 원본을 입력했다.
