# 영감보관함에서 다시 설계한 스타일

[실행](index.html) · [49장별 관찰](영감-분석/index.html) · [검토 목록과 원본 해시](영감-분석/검토-목록.json)

## 이전 시안의 문제

모노·에디토리얼·스튜디오는 같은 컬렉션 화면에 색·서체·모서리만 바꾼 구성이었다. 베이지 명조와 연두색 카드는 보관함의 그림·타이포·구도에서 충분한 근거를 찾기 어려웠다. 좋아하는 포스터 두 장을 콘텐츠로 넣는 것만으로는 사용자의 취향을 스타일로 옮겼다고 볼 수 없었다.

## 검토 범위와 해석

이미지 49장 전체를 브라우저 모음 화면으로 확인했다. 앱화면 11장, 그래픽포스터 13장, 인물 10장, 캐릭터 9장, 설명도해 4장, 명함 2장이다. 날씨 앱·바다 홈화면·고양이 선화·비행기 포스터는 원본을 확대해 구도와 선을 추가로 확인했다. 파일별 관찰과 해석은 위 검토 목록에 남겼다. 원본 파일은 수정하지 않았다.

반복해서 관찰한 특징은 제한된 색, 넓은 여백, 큰 중심 요소와 작은 기능 정보의 대비, 단순하면서 개성 있는 선화, 수평 면으로 이루어진 풍경이다. 사용자가 개별 이미지의 어느 부분을 선호하는지 직접 표시한 것은 아니므로, 이를 UI로 옮기는 과정은 디자인 해석이다.

인물 그림 한 장의 베이지 배경을 베이지 UI 선호로 일반화하지 않았다. 보라 의상의 인물, 사진 포스터, 입체 화분 화면도 같은 스타일로 뭉뚱그리지 않았다. 각 이미지의 주인공·색·구도 중 이번 사전의 기능과 연결되는 부분을 선택했다.

## 세 가지 적용

| 스타일 | 근거 | 구도·타이포 | 조작 요소 |
|---|---|---|---|
| 선화 | MYTURN 격자, Karita 명함, 흑백 캐릭터 | 얇고 명확한 경계, 작은 선 그림, 큰 가는 숫자, 충분한 여백 | 각진 입력선, 윤곽 버튼, 경계가 분명한 탭, 작은 단색 그림자 알림 |
| 컬러블록 | Sushi 파랑 타이포, 노랑 버튼 포스터, Lemon 색 띠 | 코발트·라임·밝은 중립색, 큰 굵은 숫자, 기능별 넓은 색면 | 사각 분할 탭, 굵은 진행 막대, 라임 선택 상태, 평평한 알림 |
| 풍경 | 바다·집 홈화면, 밤하늘 비행기 | 수평 색면, 작은 사물 하나, 회청색·남색·모래색, 가는 숫자 | 둥근 주요 버튼, 밑줄 입력, 낮은 높이의 진행 막대, 낮은 대비의 면과 읽기 쉬운 글자 |

사전의 로고·흰 외곽 화면·검색과 분류는 유지한다. 표현의 변화는 예시와 패턴 안에서 비교할 수 있다. ‘기본’ 중립 스타일도 남겨 두었다.

## 색 테마에 그치지 않는 적용

스타일 페이지에서 같은 기능의 **집중·입력·피드백** 예시를 나란히 비교한다. 타이머 시작·일시정지·시간 선택, 할 일 체크, 필수 입력 오류·완료, 알림 닫기·다시 실행이 동작한다. 제품 설명을 추가하는 대신 사용자가 직접 확인할 수 있게 했다.

선택은 대표 패턴 16개의 미리보기·상세 체험·비교·저장에 연결된다. 탭, 입력, 진행률, 빈 상태, 페이지 나누기 등은 스타일별 구조 규칙을 추가해 동일한 둥근 카드의 색상 변경을 넘어가도록 했다. 새로고침 후에도 선택한 스타일이 유지된다.

각 스타일 아래의 ‘참고 이미지’를 펼치면 근거가 된 원본 3장을 볼 수 있다. 예시의 선 그림과 바다 장면은 HTML과 함께 렌더하는 작은 SVG UI 그래픽으로 새로 구성했다. 원본 포스터·캐릭터를 편집하거나 원본 그림을 새 제작 자산으로 표시하지 않았다. 이 업데이트에는 image_gen을 사용하지 않았다.

기존 저장 데이터의 `clear`·`ink`·`calm` 식별자는 유지한다. 표시 이름과 스타일은 각각 기본·선화·풍경으로 갱신되므로, 과거에 저장한 에디토리얼·스튜디오 조합에도 새 표현이 적용된다. 새 컬러블록은 `block` 식별자를 사용한다.

## 검증

[실행 결과](검증-결과.json)에 기존 탐색·비교·체험·저장과 새 스타일 조작 검사를 함께 기록한다. 320·390·768px에서 세 가지 예시의 가로 넘침과 콘텐츠 잘림을 검사한다. 좁은 입력 예시에서 발견한 하단 잘림은 고정 높이를 없애고 내용에 맞게 늘어나도록 수정했다.

기능 검사 통과가 미적 만족이나 실제 사용자 연구를 대신하지는 않는다. 현재 범위는 대표 패턴 16개와 세 스타일 계열 및 기본 스타일의 로컬 실행 시안이다.
