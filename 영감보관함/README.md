# 영감 보관함

마음에 든 컨셉과 이미지를 모아 두는 곳이다. 정리 규칙은 아래 두 가지뿐이다.

| 폴더 | 넣는 것 |
|---|---|
| [이미지/](이미지/) | 스크린샷, 사진, 캡처 등 그림 파일 |
| [컨셉/](컨셉/) | 글로 적어 둔 생각, 참고 주소, 메모 |

## 파일 이름

`날짜-무엇-어디서` 순서로 적으면 나중에 찾기 쉽다.

```
2026-09-22-카드-여백이-넓은-레이아웃-linear.png
2026-09-22-어두운-화면-색-조합.md
```

출처 주소가 있으면 이미지와 같은 이름의 `.md` 파일을 컨셉 폴더에 두고 주소를 적어 둔다.
