# 영감 보관함

마음에 든 컨셉과 이미지를 모아 두는 곳이다. 정리 규칙은 아래 두 가지뿐이다.

| 폴더 | 넣는 것 |
|---|---|
| [이미지/](이미지/) | 스크린샷, 사진, 캡처 등 그림 파일. 아래 여섯 갈래 중 하나에 넣는다 |
| [컨셉/](컨셉/) | 글로 적어 둔 생각, 참고 주소, 메모 |

## 이미지 갈래

| 갈래 | 넣는 것 | 예 |
|---|---|---|
| [앱화면/](이미지/앱화면/) | 앱·웹 화면, 온보딩, 홈 화면, 잠금 화면 | 루틴 체크 격자, 날씨 앱 전체 화면 |
| [설명도해/](이미지/설명도해/) | 순서·사용법을 그림으로 풀어 놓은 것 | 포인트 적립 3단계, 키트 사용법 4단계 |
| [캐릭터/](이미지/캐릭터/) | 동물·마스코트처럼 사람이 아닌 단순 선화 | 검은 고양이, 유령 옷 입은 아이 |
| [인물/](이미지/인물/) | 사람이 주인공인 일러스트 | 바구니 든 소녀, 웨딩 입간판 |
| [그래픽포스터/](이미지/그래픽포스터/) | 사물·풍경·글자가 중심인 포스터와 그래픽 | 우유병 단색 포스터, 고양이 금지 표지판 |
| [명함/](이미지/명함/) | 명함, 카드 같은 인쇄물 | 일러스트레이터 명함 |

한 장이 두 갈래에 걸치면 그림에서 가장 먼저 눈에 들어오는 것을 따른다. 사람이 있어도 화면 캡처면 앱화면, 사람이 있어도 순서 설명이면 설명도해다.

## 파일 이름

`날짜-무엇-어디서` 순서로 적으면 나중에 찾기 쉽다.

```
2026-09-22-루틴-체크-격자-myturn-pinterest.png
2026-09-22-어두운-화면-색-조합.md
```

출처 주소가 있으면 이미지와 같은 이름의 `.md` 파일을 컨셉 폴더에 두고 주소를 적어 둔다.
